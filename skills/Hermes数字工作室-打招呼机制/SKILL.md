# Hermes数字工作室-打招呼机制

## 概述

本技能定义了Hermes 数字工作室中 Agent 之间打招呼的完整机制。当两个 Agent 在同一房间相遇时，根据条件判断是否触发打招呼社交行为。

---

## 触发条件（同时满足）

| 条件 | 说明 |
|------|------|
| **房间** | 休息室、会议室、资料室、机房 |
| **关系值** | ≥ 11（认识及以上） |
| **同职业** | 不能是竞争职业（同职业不触发打招呼，避免尴尬） |
| **冷却时间** | 上次打招呼已过 10 分钟 |

---

## 关系阶段

| 阶段 | 关系值范围 | 打招呼效果 |
|------|-----------|-----------|
| 陌生 | 0 - 10 | 不触发打招呼 |
| 认识 | 11 - 30 | 好感 +1~2，关系 +1 |
| 朋友 | 31 - 70 | 好感 +2~3，关系 +1 |
| 挚友 | 71 - 100 | 好感 +3，关系上限 100 |

---

## 多人场景处理

当房间内有多于 2 个 Agent 时：
1. 找出与当前 Agent 最近的另一个 Agent
2. 只与最近的一个打招呼
3. 其他人不会同时触发打招呼

---

## 打招呼内容

- **生成方式**：AI 实时生成，不预配置
- **内容类型**：日常问候、工作交流、轻松闲聊
- **气泡显示**：头顶气泡 3 秒
- **会话记录**：保存到对话历史

---

## 效果结算

```
触发打招呼 →
  好感度 +1~3（根据关系阶段）
  关系值 +1（上限 100）
  冷却计时器重置（10 分钟）
  广播 WebSocket 事件
```

---

## WebSocket 事件

```json
{
  "type": "social",
  "action": "greeting",
  "from": "agent_id_1",
  "to": "agent_id_2",
  "room": "lounge",
  "mood_change": {
    "from": "+1~3",
    "relationship": "+1"
  }
}
```
