# Hermes数字工作室-任务竞争机制

## 概述

本技能定义了Hermes 数字工作室中 Agent 之间任务竞争的机制。当 AI 推理发现某任务只需一个特定职业的 Agent，但场景中存在多个该职业 Agent 时，触发竞争抽签。

---

## 触发条件

| 条件 | 说明 |
|------|------|
| **任务需求** | 只需要 1 个特定职业 Agent |
| **竞争者** | 场景中存在 ≥2 个该职业 Agent |
| **职业冲突** | Agent 职业相同 |
| **双方空闲** | 竞争者都处于空闲状态 |

---

## 竞争方式

> **纯随机抽签** — 不支持举手、不支持先到先得

```
触发竞争 →
  收集所有符合条件的竞争者 →
  随机抽签决定赢家 →
  即时结算情绪效果 →
  广播竞争结果
```

---

## 效果结算

| 结果 | 情绪变化 | 说明 |
|------|---------|------|
| **赢家** | +8~15 | 随机值 |
| **输家** | -5~10 | 随机值 |
| **赢家任务失败** | 额外 -（加倍） | 情绪额外扣除 |

---

## 竞争动画（3 秒）

```
第 1 秒：宣布竞争开始
第 2 秒：抽签动画
第 3 秒：公布结果
```

### 动画内容
- 全屏或房间内显示竞争公告
- 抽签滚动动画
- 结果揭晓 + 情绪变化数字飘字

## WebSocket 事件

### 竞争开始
```json
{
  "type": "competition",
  "action": "start",
  "task_id": "xxx",
  "job": "设计师",
  "candidates": ["agent_1", "agent_2"],
  "duration": 3000
}
```

### 竞争结果
```json
{
  "type": "competition",
  "action": "result",
  "task_id": "xxx",
  "winner": "agent_1",
  "losers": ["agent_2"],
  "emotion_change": {
    "agent_1": "+8~15",
    "agent_2": "-5~10"
  },
  "animation": "draw_result"
}
```

### 任务失败额外惩罚
```json
{
  "type": "competition",
  "action": "failed_winner",
  "task_id": "xxx",
  "winner": "agent_1",
  "penalty": "-10~20",
  "reason": "任务完成质量差"
}
```

---

## 竞争安全规则

1. **冷却保护**：同一任务不会重复竞争
2. **状态保护**：忙碌中的 Agent 不参与竞争
3. **距离保护**：如果候选者距离任务地点相同或更近，有轻微加权（但不改变抽签本质）
4. **最小影响**：竞争不影响关系值，只影响情绪
