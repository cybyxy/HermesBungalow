## 1. 事件系统

### 1.1 事件分类

| 事件类型 | 说明 | 触发方式 |
|----------|------|----------|
| 突发挑战 | 紧急问题需要处理 | 随机/条件触发/用户输入AI推理 |
| 机会事件 | 可选择接受/拒绝 | 随机触发 |
| 周期事件 | 定时发生的事件 | 时间触发 |
| 里程碑事件 | 重大节点 | 条件触发 |
| 城主事件 | 城主专属事件 | 城主行为触发 |

### 1.2 AI推理挑战机制（新增）

用户可以通过文字描述自定义挑战场景，系统调用AI推理分析后生成对应的事件。

```
用户输入 → AI推理分析 → 生成挑战类型 → 评估影响 → 推荐策略 → 生成选项
```

**AI推理输出格式**：
```yaml
挑战类型: [分类]
影响评估:
  - 进度影响: ±X%
  - 情绪影响: ±X
  - 积分影响: ±X
  - 其他: [描述]
推荐策略: [最优/次优/保守]
应对选项:
  - 选项1: [描述]
  - 选项2: [描述]
```

### 1.4 AI推理接口（新增）

```typescript
// 挑战推理请求
interface ChallengeInferenceRequest {
  userDescription: string;  // 用户输入的挑战描述
  context: {
    currentTasks: Task[];
    agentStates: AgentState[];
    resourceStatus: ResourceStatus;
    timePressure: number;  // 0-100 时间压力指数
  };
}

// AI推理响应
interface ChallengeInferenceResponse {
  challengeType: 'token' | 'quality' | 'customer' | 'team' | 'resource' | 'external' | 'custom';
  severity: 'low' | 'medium' | 'high' | 'critical';
  
  impactAssessment: {
    progressImpact: number;     // -100 ~ +100
    moodImpact: number;          // -50 ~ +50
    pointImpact: number;         // -500 ~ +500
    relationshipImpact: number;   // -20 ~ +20
    description: string[];
  };
  
  recommendedStrategy: 'accept' | 'negotiate' | 'resist' | 'compromise' | 'delay';
  
  options: {
    id: string;
    title: string;
    description: string;
    effects: EventEffect[];
    risk: 'low' | 'medium' | 'high';
    expectedOutcome: string;
  }[];
  
  generatedOptions: boolean;  // 是否是自定义生成的选项
}
```

### 1.8 事件状态机

#### 1.8.1 事件生命周期

```
事件触发 → 等待主agent选择 → 执行效果 → 事件结束
     ↑
   暂停（如有）
```

#### 1.8.2 事件数据结构

```typescript
interface GameEvent {
  id: string;
  type: 'challenge' | 'opportunity' | 'periodic' | 'milestone';
  severity: 'low' | 'medium' | 'high' | 'critical';

  // 显示信息
  icon: string;
  title: string;
  description: string;

  // 选项
  choices: EventChoice[];

  // 状态
  status: 'pending' | 'resolved' | 'expired';
  triggeredAt: number;
  deadline?: number;  // 可选截止时间

  // 影响
  effects: EventEffect[];
}

interface EventChoice {
  id: string;
  text: string;
  description: string;
  effects: EventEffect[];
  cost?: {
    points?: number;
    cooldown?: boolean;
  };
  successRate?: number;  // 可选成功率
}

interface EventEffect {
  type: 'mood' | 'energy' | 'social' | 'xp' | 'points' | 'relationship' | 'skill';
  target?: string;      // Agent ID，可选
  value: number;
  duration?: number;    // 持续秒数
}
```

### 2.1 成就分类

| 分类 | 图标 | 说明 |
|------|------|------|
| 里程碑 | 🏆 | 城主等级、累计积分等硬核数据 |

```typescript
interface Achievement {
  id: string;

  icon: string;
  category: 'milestone' | 'collab' | 'efficiency' | 'social' | 'random' | 'citylord';
  rarity: 'common' | 'rare' | 'legendary';

  // 解锁条件

  // 奖励
  reward: {
    points?: number;
    xp?: number;
    skill?: string;
    item?: string;
    buff?: string;
  };

  // 状态
  unlocked: boolean;
  unlockedAt?: number;
}

interface AchievementCondition {
  type: string;          // 条件类型
  target?: string;       // 目标对象
  value?: number;        // 目标数值
  count?: number;        // 计数
}
```

```python
    for achievement in ALL_ACHIEVEMENTS:
        if achievement.unlocked:
            continue

        condition = achievement.condition

        if condition.type == 'first_task_complete':
            if game_state.tasks_completed >= 1:
                unlock_achievement(achievement)

        elif condition.type == 'continuous_perfect_match':
            if game_state.consecutive_perfect_matches >= 10:
                unlock_achievement(achievement)

        elif condition.type == 'relationship_value':
            agent = get_agent(condition.target)
            if agent.relationship_value >= condition.value:
                unlock_achievement(achievement)

        # ... 其他条件类型
```

## 4. 周目标系统

### 4.1 目标周期

| 周期 | 长度 | 重置时间 |
|------|------|----------|
| 周目标 | 7天 | 每周一 00:00 |

### 4.2 目标类型

#### 4.2.1 任务目标

| 类型 | 说明 | 示例 |
|------|------|------|
| 完成任务数 | 完成指定数量任务 | 完成5个任务 |
| 协作任务数 | 完成指定数量协作任务 | 完成2个协作任务 |
| 高匹配度任务 | 100%匹配度完成任务 | 连续10次100%匹配 |

#### 4.2.2 成长目标

| 类型 | 说明 | 示例 |
|------|------|------|
| 升级目标 | 达到指定等级 | Agent达到Lv.3 |
| 积分目标 | 累计获得积分 | 累计获得500积分 |

#### 4.2.3 社交目标

| 类型 | 说明 | 示例 |
|------|------|------|
| 关系目标 | 与某Agent关系达到 | 与小美关系达到60+ |
| 社交互动 | 进行指定次数社交 | 进行10次社交互动 |

#### 4.2.4 城主目标

| 类型 | 说明 | 示例 |
|------|------|------|
| 城主等级 | 城主达到指定等级 | 城主达到Lv.2 |
| 城主技能 | 解锁指定技能 | 解锁"精准分配"技能 |

### 4.3 目标生成

#### 4.3.1 生成规则

- 每周一自动生成7个周目标
- 目标分3个难度等级：
  - 简单（绿色）：80%完成率
  - 中等（黄色）：50%完成率
  - 困难（红色）：20%完成率

#### 4.3.2 目标数据结构

```typescript
interface WeekGoal {
  id: string;
  type: 'task' | 'growth' | 'social' | 'cityLord';
  name: string;
  description: string;
  difficulty: 'easy' | 'medium' | 'hard';
  
  target: number;      // 目标值
  current: number;     // 当前进度
  
  reward: {
    points?: number;   // 积分奖励
    xp?: number;       // XP奖励
    skill?: string;    // 技能解锁
    item?: string;     // 物品奖励
  };
  
  deadline: number;     // 截止时间戳
}
```

### 4.4 进度追踪

#### 4.4.1 进度显示

底部状态栏显示周目标进度：

```
📅 周目标 (3/7天)
[████████░░░░░░░░░░░] 3/5任务  2/3升级
奖励: 休息室L2解锁
```

#### 4.4.2 进度更新时机

| 更新时机 | 说明 |
|----------|------|
| 任务完成 | 更新任务类目标进度 |
| 协作完成 | 更新协作类目标进度 |
| 升级 | 更新成长类目标进度 |
| 社交互动 | 更新社交类目标进度 |

### 4.5 奖励机制

#### 4.5.1 完成奖励

| 完成条件 | 奖励 |
|----------|------|
| 完成全部周目标 | 稀有奖励（设施升级/技能点） |
| 完成70%+目标 | 中等奖励（积分/XP） |
| 完成50%+目标 | 基础奖励（少量积分） |
| 完成不足50% | 无奖励 |

#### 4.5.2 奖励类型

| 类型 | 奖励内容 |
|------|----------|
| 积分 | +100~500 |
| XP | +50~200 |
| 设施升级 | 解锁新设施/升级现有设施 |
| 技能点 | 城主技能点+1 |
| 头像框 | 特殊头像框解锁 |

### 4.6 周结算

#### 4.6.1 结算时间

每周一 00:00 进行周结算

#### 4.6.2 结算流程

```
检查目标完成度 → 计算奖励 → 发放奖励 → 重置目标 → 生成新目标
```

#### 4.6.3 惩罚机制

| 完成率 | 惩罚 |
|--------|------|
| <30% | 扣50积分，全员情绪-10 |
| 30-50% | 无惩罚 |
| >50% | 无惩罚 |

## 6. 系统间联动

### 6.1 事件与成就联动

事件系统与成就系统紧密关联：
- 完成首个事件触发"初出茅庐"里程碑成就
- 成功化解10次重大危机解锁"危机处理专家"城主成就
- 连续完成所有周目标触发"全勤城主"成就
- 新手引导完成后解锁"初出茅庐"成就

### 6.2 事件与周目标联动

- 每日结算事件更新周目标进度
- 周结算事件检查和发放周目标奖励/惩罚
- 每周小型挑战和每月大型挑战计入周目标任务完成数

### 6.3 事件与庆功复盘联动

- 完成里程碑或大型挑战后自动触发庆功/复盘流程
- 团队危机事件中"发起庆功宴"选项直接跳转至庆功系统
- 庆功/复盘效果影响Agent情绪状态，进而影响成就系统

### 6.4 新手引导与事件联动

- 新手引导完成后自动触发里程碑事件"首次任务完成"
- 引导过程中屏蔽非必须的突发挑战事件
- 引导完成后开始启用完整的周期事件和随机事件系统
