## 一、概述

Hermes数字工作室是一个以Agent职场模拟为核心的实时游戏系统。游戏时间与现实时间完全同步，所有数值基于真实人类的生理、心理、社会行为规律设计。

**核心原则**：
- **实时同步**：游戏内时间与现实时钟完全一致，1游戏秒 = 1现实秒
- **真实人类1:1模拟**：所有数值（饱食度、专注力、社交需求、情绪、睡意）基于真实人类生理数据
- **日夜循环**：根据现实时间自动切换游戏阶段（早晨/中午/下午/傍晚/夜晚）

**游戏循环**：通过主agent（城主）管理Agent团队，分配任务、维护设施、应对事件，模拟真实的职场管理体验。

### 2.4 游戏刻（Game Tick）

虽然时间与现实同步，但游戏逻辑仍按固定间隔更新：

| 项目 | 间隔 | 说明 |
|------|------|------|
| 状态更新 | 1秒 | Agent状态、属性变化 |
| 任务进度 | 1秒 | 任务进度计算 |
| 事件检查 | 5秒 | 随机事件判定 |
| UI推送 | 1秒 | WebSocket状态推送 |

### 2.5 实时系统

#### 2.5.1 实时渲染

- **Agent移动**：实时移动，速度为3像素/帧
- **气泡显示**：3秒后消失（打招呼/协作交流）
- **动画帧率**：150ms/帧
- **实时渲染对象**：Agent移动（60fps）、气泡显示（动画控制）、头顶状态（实时跟随Agent）、特效动画（按需）

#### 2.5.2 移动系统

```typescript
interface Movement {
  agentId: string;
  fromRoom: string;
  toRoom: string;
  path: string[];          // 经过的房间ID列表
  progress: number;        // 0-1 移动进度
  speed: number;           // 3像素/帧
  estimatedTime: number;   // 预计耗时（毫秒）
}
```

**移动计算**：
```
移动耗时 = 路径总距离 / 移动速度
         = (格子数 × 32像素) / 3像素/帧
         = 格子数 × 11帧
         ≈ 格子数 × 1.65秒
```

### 2.9 时间相关计算

```typescript
// 游戏刻编号计算
function getTurnFromTime(gameTime: GameTime): number {
  return (gameTime.day - 1) * 24 + gameTime.hour;
}

function getTimeFromTurn(turn: number): GameTime {
  return {
    day: Math.floor(turn / 24) + 1,
    hour: turn % 24,
    minute: 0
  };
}

// 真实时间转换
const TICK_DURATION_MS = 1000; // 1秒

function getRealTimeFromTurn(turn: number): number {
  return turn * TICK_DURATION_MS;
}

function getTurnFromRealTime(ms: number): number {
  return Math.floor(ms / TICK_DURATION_MS);
}
```

## 三、Agent需求系统与数值

### 3.1 核心属性定义

Agent有5个核心属性，模拟真实人类生理与心理状态：

| 属性 | 英文 | 最小值 | 最大值 | 初始值 | 真实对应 |
|------|------|--------|--------|--------|----------|
| 饱食度 | energy | 0 | 100 | 100 | 血糖/饥饿感/体能 |
| 专注力 | focus | 0 | 100 | 100 | 认知资源/精神状态 |
| 社交需求 | socialNeed | 0 | 100 | 30 | 孤独感/社交渴望 |
| 情绪值 | mood | 0 | 100 | 75 | 心情/心理健康 |
| 睡意 | sleepiness | 0 | 100 | 0 | 困倦程度 |

**数据模型**：
```typescript
energy: number;         // 饱食度 0-100
focus: number;          // 专注力 0-100
socialNeed: number;     // 社交需求 0-100
mood: number;           // 情绪值 0-100
sleepiness: number;     // 睡意 0-100
```

**需求降至0的影响**：
| 属性 | 降至0的影响 |
|------|-------------|
| 饱食度(energy) | 工作效率-50% |
| 电量/quota | 无法工作 |
| 社交需求(socialNeed) | 工作质量下降，汇报变差 |
| 情绪值(mood) | 无法工作，需干预 |
| 睡意(sleepiness)达到100 | 强制睡眠 |

### 3.2 真实消耗率

#### 饱食度（energy）— 真实血糖曲线模拟

| 状态 | 消耗/秒 | 消耗/小时 | 8小时工作消耗 | 真实对应 |
|------|---------|-----------|---------------|----------|
| 空腹（刚起床） | 0 | 0 | — | 基础代谢 |
| 轻度工作 | -0.004 | -14.4 | -115.2 | 脑力工作 |
| 中度工作 | -0.006 | -21.6 | -172.8 | 体力+脑力 |
| 重度工作 | -0.008 | -28.8 | -230.4 | 高强度专注 |
| **睡眠恢复** | **+0.014** | **+50** | **+400（8小时）** | 消化吸收 |

> **真实对照**：真实人类空腹8小时血糖消耗约30-40%，睡眠时激素调节慢慢恢复。游戏中设定8小时睡眠恢复约50点。

#### 专注力（focus）— 真实认知疲劳曲线

| 状态 | 消耗/秒 | 消耗/小时 | 4小时工作消耗 | 真实对应 |
|------|---------|-----------|---------------|----------|
| 休息状态 | 0 | 0 | — | 被动恢复 |
| 轻度专注 | -0.008 | -28.8 | -115.2 | 看邮件/开会 |
| 中度专注 | -0.012 | -43.2 | -172.8 | 常规工作 |
| 高度专注 | -0.017 | -60 | -240 | 深度工作 |
| **睡眠恢复** | **+0.028** | **+100** | **+800（8小时）** | 认知完全恢复 |

> **真实对照**：人类认知疲劳在连续深度工作2-4小时后急剧下降，需要休息恢复。专注力在4小时高度工作后耗尽。

#### 社交需求（socialNeed）— 真实孤独感模型

| 状态 | 变化/秒 | 变化/小时 | 真实对应 |
|------|---------|-----------|----------|
| 独处工作 | +0.028 | +100/小时 | 工作中无社交 |

### 4.1 职业匹配度系统

任务类型与Agent职业匹配度影响工作效率和产出质量。

| 匹配等级 | 匹配度范围 | 效率修正 | 质量修正 | 特殊效果 |
|----------|------------|----------|----------|----------|
| 完全匹配 | 90-100% | +30% | +20% | 无 |
| 基本匹配 | 60-89% | ±0% | ±0% | 无 |
| 不匹配 | 20-59% | -30% | -20% | 匹配度持续下降 |
| 严重不匹配 | <20% | -60% | — | **触发消极怠工** |

**消极怠工（slacking）表现**：
- 状态显示 😤 表情
- 移动速度变为 1格/4秒（正常为 1格/2秒）
- 汇报质量明显下降
- 连续不匹配会导致匹配度继续下降，甚至拒绝工作

**城主应对策略**：分配匹配任务恢复匹配度、主动发起休息室社交活动、升级设施加速恢复。

```
项目完成 → 宣布庆功/自动触发
    → 所有Agent移动至休息室（移动动画）
    → 休息室变成"庆功模式"（装饰+特效）
    → 每个Agent发表"获奖感言"
    → 全员情绪值+20
    → 主agent可发表"城主寄语"
    → 庆功结束，Agent返回岗位
```

**庆功效果**：

| 效果 | 数值 |
|------|------|
| 全员情绪+ | +20 |
| 关系值提升 | +5（所有Agent之间） |
| 城主XP | +15 |
| 社交需求恢复 | -30 |

### 4.13 会议室复盘系统

每个项目完成后，团队到会议室进行复盘，总结经验教训。

**触发方式**：自动（每个项目完成后）或跳过（简单任务的小复盘）。

**复盘流程**：
```
项目完成 → 宣布复盘会议/自动触发
    → 所有Agent移动至会议室（移动动画）
    → 会议室变成"复盘模式"
    → 主agent主持复盘
    → 每个Agent轮流发言：Good/Better/Best Practice
    → 主agent总结点评
    → 复盘结束，获得复盘奖励
```

**复盘环节**：

| 环节 | 内容 | 效果 |
|------|------|------|
| 👍 Good | 分享做得好的点 | 全员"信心+" |
| 💪 Better | 反思需要改进的点 | 指定属性提升 |
| 🎯 Best Practice | 形成可复用经验 | 存入资料室知识库 |
| 📝 主agent点评 | 总结+鼓励 | 全员情绪+10 |

**复盘奖励**：

| 属性 | 提升值 | 说明 |
|------|--------|------|
| 工作积极性 | +5~15 | 根据复盘质量浮动 |
| 经验值(XP) | +20~50 | 根据参与度浮动 |
| 情绪值 | +10 | 主agent点评后获得 |
| 社交需求 | -20 | 团队交流消耗社交需求 |

**复盘等级**：

| 复盘类型 | 适用场景 | 奖励倍率 |
|----------|----------|----------|
| 快速复盘 | 简单任务 | x0.5 |
| 标准复盘 | 普通项目 | x1.0 |
| 深度复盘 | 里程碑/大型挑战 | x2.0 |

### 4.16 休息室生活设施系统

休息室配备咖啡机和零食贩卖机，Agent长时间工作后主动前往休息恢复。完整的数值体系参见第3.7节（物品与消费系统）。

**咖啡机（免费）**：
- 位置：休息室角落 | 费用：免费 | 默认解锁
- 触发条件：连续工作满2700秒（45分钟）后，或专注力(focus)<60
- 效果：专注力+25，能量+10，情绪+5，睡意-10
- 效率加成：+15%，持续3600秒
- 行为流程：连续工作45分钟+(focus<60) → AI判断 → 移动至休息室(10秒) → 喝咖啡动画(15秒) → 返回岗位(10秒)，总耗时约45秒

**零食贩卖机（付费）**：
- 位置：休息室角落 | 费用：5~12积分/次 | 解锁需300积分
- 触发条件：连续工作满3600秒（60分钟）后，或能量(energy)<50 或 社交需求>60
- 详情参见第3.7.2节

**午餐机制（强制休息）**：
- 触发条件：连续工作满14400秒（4小时）后，或游戏内12:00-13:00
- 详情参见第3.3节

**分享零食**：
- 触发条件：关系值≥31的朋友同时在休息室
- 详情参见 `04-社交与情绪系统.md` 第6章

> **详细文档**：`06-物品与UI布局.md`

### 4.17 社交机制

#### 打招呼机制

**触发场景**：休息室、会议室、资料室、机房
**触发条件**：Agent进入房间遇到已有Agent、关系值≥11且非竞争关系、冷却10分钟
**效果**：好感度+1~3，关系值+1（上限100）

**打招呼内容分层**：

| 关系阶段 | 问候方式 |
|----------|----------|
| 认识 | 点头示意 |
| 朋友 | 友好问候 |
| 挚友 | 热情招呼 |

#### 协作交流机制

- 触发条件：协作任务状态时
- 表现形式：头顶气泡 + 会话记录，气泡停留3-5秒
- 城主监听模式：选择监听则AI生成协作对话内容；不监听时本地模板显示状态，节省token
- 效率加成：AI实时生成，上限+5%

> **详细文档**：`04-社交与情绪系统.md`（第3-5章）

### 4.18 任务竞争机制

**真实职场模拟**：真实职场中，同事之间会因为项目机会产生竞争。

**触发条件**：
| 条件 | 说明 |
|------|------|
| 主agent判定 | 任务只需1人 |
| 同职业Agent | 场景中存在≥2个同类空闲Agent |
| 多个"举手" | Agent通过AI判断主动竞争 |
| 非协作任务 | 协作者任务不触发竞争 |

**竞争方式**：公平抽签，每个举手Agent等概率中签（无加权）。

**竞争过程可视化**：
```
【竞争】设计师{AgentA}和{AgentB}同时举手抢任务
    → 抽签中...（显示3秒思考动画）
    → 🎉 {AgentA}抢到了！显示"我来！"气泡（5秒）
    → 😔 {AgentB}没抢到，显示"下次再..."气泡（5秒）
```

**竞争结果与影响**：

| 结果 | 情绪变化 | 关系变化 | 持续时间 | 真实心理 |
|------|---------|---------|---------|----------|
| 抢到任务 | **+8~15** | — | 即时 | 被认可的成就感 |
| 没抢到 | **-5~10** | 与赢家 **-3~-5** | 30分钟 | "为什么不是我"的失落/嫉妒 |
| 抢到+完美完成 | +30（英雄感） | 与同事 +3 | 即时 | 证明自己的高光时刻 |
| 抢到+失败 | **-30~-50**（加倍惩罚） | 与同事 -5 | 3小时 | 压力巨大+自责+丢脸 |

**加倍惩罚判定**：
| 判定条件 | 说明 |
|----------|------|
| 任务彻底失败 | TaskStatus = 'failed' |
| 进度严重落后 | 超时50%以上 |
| 主agent评分<2分 | 城主评价不满意 |

> **详细文档**：`03-任务与竞争系统.md`（待编写）
