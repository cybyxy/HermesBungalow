### 1.3 顶栏内容

- **9个Agent选择按钮**：崽 / 沈 / 顾 / 江 / 秦 / 马 / 苏 / 林 / 陆
- **XP值**：当前城主经验值
- **刷新按钮**：刷新界面状态
- **无**游戏时间/城主信息显示

### 1.4 中央画布

- 940 × 493px Canvas（实际运行版）
- 1400 × 900px 活动空间（设计原型版）
- 无独立左侧面板（整合到底栏）
- 显示基地建筑和Agent活动

### 1.5 右侧面板

- 仅"清空"按钮（清空消息区）
- 无独立任务列表（日志整合到消息系统）

- **7个菜单按钮**：👥Agent / 📋任务 / 💬社交 / 👑城主 / 🏠基地 / 🎲事件 / ❓帮助
- **4个动作按钮**：新建 / 分配 / 技能 / 发送
- **消息输入框**：右下角，支持Markdown语法
- **特殊语法**：`/relay 对方|消息` 可指定消息收件人

### 1.7 渲染顺序

1. 背景 (bg)
2. 顶栏 (top)
3. 底栏 (bottom)
4. 中央活动空间
5. 左面板（半透明覆盖）
6. 右面板（半透明覆盖）

### 2.3 建筑尺寸计算

```javascript
// 界面布局
const LAYOUT = { top: 44, bottom: 56, left: 260, right: 260 };
const CENTER_W = 1920 - 260 - 260;  // 1400
const CENTER_H = 1000 - 44 - 56;    // 900

// 建筑常量
const WALL = 6;
const DOOR = 24;
const VISUAL_CORRIDOR_W = 32;   // 中间纵向走廊
const MID_CORRIDOR_H = 32;      // 横向走廊
const BOTTOM_CORRIDOR_H = 32;   // 底部走廊
const KING_H_RATIO = 1.2;       // 城主办公室高度比例
const V_CORR_H = 14;            // 垂直走廊

// 房间尺寸计算
// CENTER_H = KING_H + V_CORR_H + 3*ROOM_H + 2*MID_CORRIDOR_H + BOTTOM_CORRIDOR_H + 5*WALL
const ROOM_H = Math.floor((900 - 14 - 32 - 64 - 30) / 4.2);  // 181
const ROOM_W = Math.floor((1400 - 30) / 4);                    // 342

// 城主办公室
const KING_W = Math.floor(ROOM_W * 1.5);  // 513
const KING_H = Math.floor(ROOM_H * 1.2);  // 217
```

## 6. 社交机制规格

### 6.1 打招呼机制

**触发场景**：休息室、会议室、资料室、机房

**触发条件**：
- Agent A 进入房间 → 遇到已在房间的Agent B
- 关系 ≥ "认识" 且非竞争关系
- 冷却时间：10分钟（同一对Agent在同地点）

**交互规则**：
- 一来一回：Agent A主动打招呼 → Agent B回应 → 结束
- 多Agent处理：如果房间已有多个Agent，与**最近的一个**打招呼
- 位置判断：同一房间即算相遇

**效果**：

| 属性 | 数值 |
|------|------|
| 好感度 | +1 ~ +3（上限100） |
| 关系值 | +1（上限100） |

**打招呼内容分层**：

| 关系阶段 | 问候方式 |
|----------|----------|
| 认识 | 点头示意 |
| 朋友 | 友好问候 |
| 挚友 | 热情招呼 |

**关系上限**：朋友 → 挚友（不允许恋人/办公室恋爱）

### 6.2 协作交流机制

**触发条件**：协作任务状态时

**表现形式**：
- 头顶气泡 + 会话记录
- 气泡停留时间：3~5秒
- 气泡独立于精灵图渲染，显示在Agent头顶
- 停留时间：3秒（协作交流时）
- 城主可监听对话内容

**城主监听模式**：
- 城主选择监听 → AI生成协作对话内容供城主查看
- 城主可随时打断参与
- 不监听时 → 本地模板显示状态，节省token

**AI调用**：按需调用，不限制频率

**效率加成**：AI实时生成，上限 +5%

**状态互斥**：打招呼状态与协作交流状态互斥
