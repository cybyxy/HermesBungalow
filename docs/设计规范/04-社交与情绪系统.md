## 3. 打招呼机制

### 3.1 触发规则

| 要素 | 说明 |
|------|------|
| **触发场景** | 休息室、会议室、资料室、机房 |
| **触发条件** | Agent A 进入房间 → 遇到已在房间的 Agent B |
| **关系要求** | 关系值 ≥ 11（认识阶段） |
| **竞争关系** | 同职业Agent存在竞争，不触发打招呼 |
| **冷却时间** | 3600秒（60分钟，同一对Agent在同地点） |
| **多Agent处理** | 如果房间已有多个Agent，与**最近的一个**打招呼 |
| **位置判断** | 同一房间即算相遇 |

### 3.2 交互规则

- **一来一回**：Agent A 主动打招呼 → Agent B 回应 → 结束
- **状态互斥**：打招呼状态与协作交流状态互斥
- **优先级**：协作交流 > 打招呼
- **气泡停留**：5秒（真实对话时间）

### 3.3 效果

| 属性 | 数值 | 上限 | 真实对照 |
|------|------|------|----------|
| 好感度 | +1~3 | 100 | 见面多了一个熟人 |
| 关系值 | +1 | 100 | 点头之交 |
| 社交需求 | -15 | — | 短暂的社交满足 |

### 3.4 打招呼内容生成

> **说明**：打招呼内容由推理模型根据 Agent 的性格、职业、当前状态和关系阶段自动实时生成，无需配置固定内容。

**生成要素**：性格、职业、关系阶段、当前场景、近期状态

**打招呼内容分层**：

## 8. 情绪感染算法

### 8.1 感染强度

| 场景 | 传染强度 | 说明 |
|------|----------|------|
| 同房间Agent | 80% | 情绪同步化 |
| 相邻房间 | 50% | 部分影响 |
| 休息室社交 | 100% | 完全同步 |
| 走廊擦肩而过 | 20% | 短暂接触 |

### 8.2 传染计算公式

```
新情绪值 = 当前情绪值 × (1 - 传染强度) + 源头情绪值 × 传染强度
```

**示例**：
- Agent A 情绪值 80（兴奋）
- Agent B 情绪值 40（平静）
- 同房间传染强度 80%

```
B的新情绪值 = 40 × (1 - 0.8) + 80 × 0.8
            = 40 × 0.2 + 80 × 0.8
            = 8 + 64
            = 72（积极）
```

### 8.3 情绪传染算法

```python
def emotion_infection(agent: Agent, nearby_agents: list[Agent], strength: float):
    """
    情绪传染算法

    Args:
        agent: 当前Agent
        nearby_agents: 附近的Agent列表
        strength: 传染强度 (0-1)
    """
    if not nearby_agents:
        return

    # 计算周围Agent的平均情绪值
    total_emotion = sum(a.emotion_value for a in nearby_agents)
    avg_emotion = total_emotion / len(nearby_agents)

    # 情绪差值越大，传染效果越强
    emotion_diff = abs(agent.emotion_value - avg_emotion)
    if emotion_diff < 5:
        return  # 情绪差异太小，不传染

    # 应用传染强度
    infection_effect = (avg_emotion - agent.emotion_value) * strength * 0.5
    agent.emotion_value += infection_effect

    # 限制在0-100范围内
    agent.emotion_value = max(0, min(100, agent.emotion_value))
```

### 8.4 传染触发条件

```python
def check_emotion_infection(agent_a: Agent, agent_b: Agent, room: Room) -> bool:
    """
    检查是否触发情绪传染
    """
    # 条件1: 两个Agent都在同一房间
    if agent_a.room_id != agent_b.room_id:
        return False

    # 条件2: 双方情绪值差异 >= 5
    if abs(agent_a.emotion_value - agent_b.emotion_value) < 5:
        return False

    # 条件3: 双方都不是离线状态
    if agent_a.status == 'offline' or agent_b.status == 'offline':
        return False

    # 条件4: 没有在冷却中（传染冷却10秒）
    cooldown_key = f"emotion_infection_{agent_a.id}_{agent_b.id}"
    if is_in_cooldown(cooldown_key):
        return False

    return True
```

### 8.5 冷却机制

```python
# 情绪传染冷却
EMOTION_INFECTION_COOLDOWN = 10  # 秒

# 同一对Agent的情绪传染冷却
# 传染发生后，设置10秒冷却
set_cooldown(f"emotion_infection_{agent_a.id}_{agent_b.id}", EMOTION_INFECTION_COOLDOWN)
```

### 8.6 感染规则

- 高情绪Agent可提升周围低情绪Agent的情绪
- 负面情绪同样会传染
- 休息室社交时情绪感染最强

## 9. 情绪病毒与团队士气危机

### 9.1 病毒判定

```python
def check_emotion_virus(agents: list[Agent], room: Room) -> bool:
    """
    检查是否触发情绪病毒

    触发条件:
    - 同一房间内有 >= 3个Agent情绪低落（<40）
    - 或 >= 2个Agent情绪焦躁（<20）
    """
    low_mood_count = sum(1 for a in agents if a.emotion_value < 40)
    distressed_count = sum(1 for a in agents if a.emotion_value < 20)

    return low_mood_count >= 3 or distressed_count >= 2
```

### 9.2 病毒传染效果

```python
def apply_emotion_virus(agents: list[Agent], room: Room):
    """
    情绪病毒传染
    - 所有在场Agent情绪下降
    - 可能传染给相邻房间
    """
    # 主要房间内传染
    for agent in agents:
        agent.emotion_value = max(0, agent.emotion_value - 10)

    # 相邻房间有一定概率传染
    for adjacent_room in room.adjacent_rooms:
        if random.random() < 0.3:  # 30%概率
            adjacent_agents = get_agents_in_room(adjacent_room)
            for agent in adjacent_agents:
                agent.emotion_value = max(0, agent.emotion_value - 5)
```

## 11. 情绪对工作的影响

### 11.1 效率计算

```python
def calculate_efficiency(agent: Agent, task: Task) -> float:
    """
    计算任务执行效率

    效率 = 基础效率 × 匹配度修正 × 情绪修正 × 技能加成
    """
    base_efficiency = 1.0

    # 匹配度修正
    match_modifier = get_match_modifier(agent, task)

    # 情绪修正
    mood_modifier = get_mood_modifier(agent.emotion_value)

    # 技能加成
    skill_bonus = get_skill_bonus(agent)

    efficiency = base_efficiency * match_modifier * mood_modifier * skill_bonus

    return max(0.1, efficiency)  # 最低10%效率
```

EMOTION_ERROR_MODIFIER = {
    'excited': 1.0,      # 无影响
    'positive': 1.0,     # 无影响
    'neutral': 1.0,       # 基准

def calculate_error_rate(agent: Agent, base_error_rate: float) -> float:

## 16. 梗触发机制

### 16.1 解锁条件检查

```python
def check_meme_unlock(agent: Agent, meme: Meme) -> bool:
    """
    检查是否解锁新梗
    """
    condition = meme.unlockCondition

    if condition.type == 'task_count':
        return agent.tasks_completed >= condition.value

    elif condition.type == 'collab_count':
        return agent.collaborations_completed >= condition.value

    elif condition.type == 'relationship':
        target = condition.target
        rel_value = agent.get_relationship(target)
        return rel_value >= condition.value

    elif condition.type == 'achievement':
        return agent.has_achievement(condition.value)

    elif condition.type == 'random':
        return random.random() < condition.value

    return False
```

### 16.2 梗使用概率

```python
# 梗使用概率配置
MEME_USAGE_PROBABILITY = {
    'common': 0.3,    # 30%概率使用
    'rare': 0.1,     # 10%概率使用
    'legendary': 0.02, # 2%概率使用
}

def should_use_meme(agent: Agent, context: str) -> Optional[Meme]:
    """
    决定是否在当前上下文使用梗
    """
    # 获取已解锁的梗
    unlocked_memes = agent.get_unlocked_memes()

    if not unlocked_memes:
        return None

    # 随机选择一个梗
    selected_meme = random.choice(unlocked_memes)

    # 根据稀有度决定是否使用
    probability = MEME_USAGE_PROBABILITY[selected_meme.rarity]

    if random.random() < probability:
        return selected_meme

    return None
```
