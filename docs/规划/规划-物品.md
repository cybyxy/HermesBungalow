## 5. 社交机制规格

### 5.1 打招呼机制

**触发场景**
- 休息室、会议室、资料室、机房

**触发条件**
- Agent A 进入房间 → 遇到已在房间的 Agent B
- 关系 ≥ "认识" 且非竞争关系
- 冷却时间：10 分钟（同一对 Agent 在同地点）

**交互规则**
- 一来一回：Agent A 主动打招呼 → Agent B 回应 → 结束
- 多 Agent 处理：如果房间已有多个 Agent，与**最近的一个**打招呼
- 位置判断：同一房间即算相遇

**效果**
| 属性 | 数值 |
|------|------|
| 好感度 | +1 ~ +3（上限 100） |
| 关系值 | +1（上限 100） |

**打招呼内容分层**
| 关系阶段 | 问候方式 |
|----------|----------|
| 认识 | 点头示意 |
| 朋友 | 友好问候 |
| 挚友 | 热情招呼 |

**关系上限**
- 朋友 → 挚友（不允许恋人/办公室恋爱）

### 5.2 协作交流机制

**触发条件**
- 协作任务状态时

**表现形式**
- 头顶气泡 + 会话记录
- 气泡停留时间：3-5秒
- 城主可监听对话内容

**城主监听模式**
- 城主选择监听 → AI生成协作对话内容供城主查看
- 城主可随时打断参与
- 不监听时 → 本地模板显示状态，节省token

**AI调用**：按需调用，不限制频率

**效率加成**
- AI 实时生成，上限 +5%

**状态互斥**
- 打招呼状态与协作交流状态互斥

## 6. 状态定义

### 6.1 Agent 状态

| 状态 | 说明 |
|------|------|
| idle | 空闲，站立待机 |
| walking | 移动中 |
| working | 执行任务中（消耗饱食度） |
| reporting | 完成任务，前往汇报 |
| social | 在休息室交流 |
| chatting | 自主交流中（Agent 间自由交流） |
| collaborating | 协作任务中 |
| slacking | 消极怠工（匹配度 <20%） |
| greeting | 打招呼中 |
| error | 错误状态 |
| offline | 离线状态 |

### 6.2 情绪状态

| 情绪 | 表情 | 效果 |
|------|------|------|
| 兴奋 | 😄 | 效率 +20% |
| 积极 | 😊 | 效率 +10% |
| 平静 | 😐 | 无加成（基准状态） |
| 低落 | 😔 | 效率 -10% |
| 焦躁 | 😤 | 效率 -20%，易出错，社交需求 + |
