# Hermes数字工作室 - UI布局规划 v3

> 基于实际运行界面更新
> 更新时间：2026-05-02

---

## 一、项目概述

**项目名称**：Hermes数字工作室 (HermesBungalow)
**项目类型**：多Agent养成经营游戏（单机Rimworld风格）
**技术栈**：React + Next.js + Phaser + TypeScript / obEspoir Python / WebSocket
**分辨率**：1920 × 1000（固定）

---

## 二、界面布局（实际运行版）

### 2.1 整体布局

```
┌──────────────────────────────────────────────────────────────────────┐
│  顶栏 (44px) — 9个Agent按钮 + XP值 + 刷新按钮                      │
├────────────────────────────────────────┬────────────────────────────┤
│                                        │                            │
│           中央画布                      │       右侧面板             │
│         (940 × 493px)                  │      （仅清空按钮）        │
│                                        │                            │
├────────────────────────────────────────┴────────────────────────────┤
│  底栏 (56px) — 7个菜单按钮 + 4个动作按钮 + 消息输入框              │
└──────────────────────────────────────────────────────────────────────┘
```

### 2.2 尺寸定义

| 元素 | 尺寸 | 说明 |
|------|------|------|
| 屏幕 | 1920 × 1000 | 固定分辨率 |
| 顶栏 | 1920 × 44 | Agent选择 + XP + 刷新 |
| 中央画布 | 940 × 493px | Canvas游戏区域 |
| 右侧面板 | 仅"清空"按钮 | 无独立任务/日志面板 |
| 底栏 | 1920 × 56 | 7个菜单 + 4个动作 + 输入框 |

### 2.3 顶栏内容

- **9个Agent选择按钮**：崽 / 沈 / 顾 / 江 / 秦 / 马 / 苏 / 林 / 陆
- **XP值**：当前城主经验值
- **刷新按钮**：刷新界面状态
- **无**游戏时间/城主信息显示

### 2.4 中央画布

- 尺寸：940 × 493px Canvas
- 无独立左侧面板（整合到底栏）
- 显示基地建筑和Agent活动

### 2.5 右侧面板

- 仅"清空"按钮（清空消息区）
- 无独立任务列表（日志整合到消息系统）

### 2.6 底栏内容

- **7个菜单按钮**：👥Agent / 📋任务 / 💬社交 / 👑城主 / 🏠基地 / 🎲事件 / ❓帮助
- **4个动作按钮**：新建 / 分配 / 技能 / 发送
- **消息输入框**：右下角，支持Markdown语法
- **特殊语法**：`/relay 对方|消息` 可指定消息收件人

## 三、基地建筑结构

### 3.1 布局层次

```
┌────────────────────────────────────────┐
│           城主办公室 (居中)             │  ← KING_W × KING_H，金色边框
├────────────────┬─────────────────────┤
│                │   垂直走廊 (24×14)    │  ← 连接城主与下方房间
├────────┬───────┼───────┬─────────────┤
│ 休息室 │ 资料室 │       │ 会议室 │ 机房 │  ← 功能室层（固定）
├────────┴───────┼───────┴─────────────┤
│     水平走廊 (32px高)                  │  ← 连接左右走廊
├────────┬───────┼───────┬─────────────┤
│办公室1 │办公室2 │       │办公室3 │办公室4│  ← 办公室层1
├────────┴───────┼───────┴─────────────┤
│     水平走廊 (32px高)                  │
├────────┬───────┼───────┬─────────────┤
│办公室5 │办公室6 │       │办公室7 │办公室8│  ← 办公室层2
├────────┴───────┼───────┴─────────────┤
│     底部走廊 (32px高)                  │  ← 最下方走廊
└────────────────────────────────────────┘
```

### 3.2 建筑尺寸计算

```javascript
// 界面布局
const LAYOUT = { top: 44, bottom: 56, left: 260, right: 260 };
const CENTER_W = 1920 - 260 - 260;  // 1400
const CENTER_H = 1000 - 44 - 56;    // 900

// 建筑常量
const WALL = 6;
const DOOR = 24;
const VISUAL_CORRIDOR_W = 32;   // 中间纵向走廊
const MID_CORRIDOR_H = 32;      // 横向走廊
const BOTTOM_CORRIDOR_H = 32;    // 底部走廊
const KING_H_RATIO = 1.2;        // 城主办公室高度比例
const V_CORR_H = 14;             // 垂直走廊

// 房间尺寸计算
// CENTER_H = KING_H + V_CORR_H + 3*ROOM_H + 2*MID_CORRIDOR_H + BOTTOM_CORRIDOR_H + 5*WALL
const ROOM_H = Math.floor((900 - 14 - 32 - 64 - 30) / 4.2);  // 181
const ROOM_W = Math.floor((1400 - 30) / 4);                    // 342

// 城主办公室
const KING_W = Math.floor(ROOM_W * 1.5);  // 513
const KING_H = Math.floor(ROOM_H * 1.2); // 217
```

### 3.3 详细尺寸表

| 元素 | 尺寸(宽×高) | 数量 |
|------|-------------|------|
| 房间 | 342 × 181 px | 10个（4功能室+6办公室） |
| 城主办公室 | 513 × 217 px | 1个 |
| 垂直走廊 | 24 × 14 px | 1个 |
| 中间纵向走廊 | 32 × 181 px | 1个（贯穿功能室+办公室层） |
| 水平走廊 | 32 × 32 px | 3个 |
| 底部走廊 | 32 × 32 px | 2个 |
| 外墙 | 8 × 建筑高 | 2个 |

### 3.4 房间类型

| 房间 | 类型 | 边框颜色 | 特殊功能 |
|------|------|----------|----------|
| 休息室 | 固定 | 蓝色 #4169E1 | 需求恢复（饱食度/社交/电量） |
| 资料室 | 固定 | 蓝色 #4169E1 | 知识库、成长档案 |
| 会议室 | 固定 | 蓝色 #4169E1 | 复盘、协作 |
| 机房 | 固定 | 蓝色 #4169E1 | Token配额管理 |
| 办公室1-8 | 动态 | 绿色 #228B22 | 动态分配给Agent工作 |
| 城主办公室 | 专属 | 金色边框 | 城主专属，效率加成 |
