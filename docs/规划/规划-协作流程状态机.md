## 1. 协作流程概述

协作是多个Agent配合完成任务的机制，需要主agent协调或由Agent自主触发。

## 2. 协作状态机

### 2.1 状态定义

| 状态 | 说明 | 入口条件 |
|------|------|----------|
| idle | 无协作 | 默认状态 |
| collab_requested | 协作请求中 | 主agent发起或Agent自主请求 |
| collab_pending | 等待确认 | 协作请求发送，等待响应 |
| collab_active | 协作进行中 | 所有参与者确认 |
| collab_holding | 协作暂停 | 等待资源或决策 |
| collab_completed | 协作完成 | 任务完成，触发结算 |
| collab_failed | 协作失败 | 协作中断或失败 |

### 2.2 状态转换图

                    │                                         │
                    ▼                                         │
┌─────────┐    ┌────────────────┐    ┌─────────────────┐   │

└─────────┘    └────────────────┘    └────────┬────────┘   │
    ▲                                          │             │
    │           ┌──────────────────────────────┘             │
    │           │ (拒绝/超时)                                 │
    │           ▼                                             │

## 3. 详细状态说明

### 3.1 idle（空闲状态）

```yaml
状态: idle
说明: 默认状态，无协作进行

进入条件:
  - 游戏开始
  - 协作完成
  - 协作失败/取消

退出条件:
  - 主agent根据AI推理结果发起协作请求

可执行动作:
  - 主agent发起协作请求
  - 自由移动
```

### 3.2 collab_requested（协作请求中）

```yaml
状态: collab_requested
说明: 协作请求已发起，等待参与者确认

进入条件:
  - 主agent根据AI推理发起协作请求

退出条件:
  - 所有Agent确认 → collab_pending
  - 任意Agent拒绝 → idle
  - 超时(5秒) → idle

数据记录:
  - 主Agent: 发起者
  - 辅助Agent[]: 被邀请者
  - 任务ID: 关联任务
  - 请求时间: 发起时间戳
```

### 3.3 collab_pending（等待确认）

```yaml
状态: collab_pending
说明: 等待各Agent确认是否参与协作

进入条件:
  - collab_requested中所有Agent未拒绝

退出条件:
  - 所有Agent确认 → collab_active
  - 任意Agent拒绝 → idle
  - 超时(3秒) → idle

每个Agent的确认状态:
  - pending: 待确认
  - accepted: 已接受
  - rejected: 已拒绝

确认检查:
  - Agent当前状态是否可以参与协作
  - Agent是否愿意参与（基于关系值）
  - Agent是否满足协作要求
```

### 3.4 collab_active（协作进行中）

```yaml
状态: collab_active
说明: 协作任务正式执行

进入条件:
  - collab_pending中所有Agent确认

退出条件:
  - 任务完成 → collab_completed
  - 被中断 → collab_holding
  - 失败 → collab_failed

进行中效果:
  - 效率+30%（双Agent）
  - 关系度≥80%时额外+15%
  - 职业互补时质量+20%
  - Token消耗-20%
  - 头顶气泡显示3秒协作对话

进度计算:
  进度 += (基础速度 × 效率加成) / 参与人数
```

### 3.5 collab_holding（协作暂停）

```yaml
状态: collab_holding
说明: 协作因某种原因暂停

进入条件:
  - 协作中任意Agent被中断
  - 等待主agent决策
  - 资源不足

暂停原因:
  - Agent电量耗尽
  - 主agent叫停
  - 需要决策

退出条件:
  - 问题解决 → collab_active
  - 超时(10秒) → collab_failed
  - 主agent取消 → idle

处理选项:
  1. 等待恢复
  2. 更换参与者
  3. 取消协作
```

### 3.6 collab_completed（协作完成）

```yaml
状态: collab_completed
说明: 协作任务成功完成

进入条件:
  - 协作任务进度达到100%

结算内容:
  - 积分奖励: +50（基础）+ 效率加成
  - XP奖励: 正常XP × 1.5
  - 城主XP: +25
  - 情绪值: +15（每个参与者）
  - 关系值: +3（参与者之间）
  - 可能触发灵感创意（额外奖励）

后续动作:
  - 自动进入汇报流程（**层层汇报**：先干系Agent交流 → 逐级向上汇报 → 至主agent）
  - 触发庆功系统（可选）
  - 触发复盘系统
  - 返回idle状态
```

### 3.7 collab_failed（协作失败）

```yaml
状态: collab_failed
说明: 协作任务失败

进入条件:
  - collab_holding超时
  - 任务无法完成
  - 主agent主动取消

失败后果:
  - 任务进度清零或保留50%
  - 参与者情绪-10
  - 关系值-2
  - 可能影响后续协作意愿

后续动作:
  - 提示主agent原因
  - 可选择重新协作
  - 返回idle状态
```

## 4. 协作数据结构

### 4.1 协作实例

```typescript
interface Collaboration {
  id: string;
  taskId: string;

  // 参与者
  initiatorId: string;      // 主Agent ID
  participantIds: string[]; // 辅助Agent ID列表

  // 状态
  status: 'requested' | 'pending' | 'active' | 'holding' | 'completed' | 'failed';

  // 确认状态
  confirmations: {
    [agentId: string]: 'pending' | 'accepted' | 'rejected';
  };

  // 时间
  createdAt: number;
  startedAt?: number;
  completedAt?: number;
  failedAt?: number;

  // 效果
  efficiencyBonus: number;  // 累计效率加成
  messages: ChatMessage[];  // 协作对话记录

  // 进度
  progress: number;        // 0-100
  holdReason?: string;     // 暂停原因
}
```

### 4.2 协作消息

```typescript
interface ChatMessage {
  id: string;
  senderId: string;
  content: string;
  timestamp: number;
  type: 'greeting' | 'collaboration' | 'chat' | 'think';
  bubbleDuration: number;  // 气泡显示时长
}
```

## 5. 协作发起方式

### 5.1 主agent发起

```
主agent选择Agent A → 主agent选择Agent B → 选择协作任务 → 确认发起
                                                      │
                                                      ▼
                                              collab_requested
```

### 5.2 Agent自主触发

```
Agent A 空闲 → Agent B 在附近 → 自主交流 → 产生协作想法
                                                    │
                                                    ▼
                                            collab_requested
```

## 7. 协作与社交的关系

### 7.1 状态互斥

| 状态 | 可同时存在 |
|------|-----------|
| 打招呼 (greeting) | ❌ 协作 (collaborating) |
| 协作 (collaborating) | ❌ 打招呼 (greeting) |

### 7.2 协作中的社交

```
协作进行中
    │
    ├── 头顶气泡显示协作对话
    │
    ├── 会话记录保存
    │
    └── 协作完成后:
        ├── 关系值+3
        └── 可能产生新梗
```
