## 二、Agent需求系统 (4.1)

**功能说明**：Agent有三个维度的需求，需要通过休息室活动恢复。

| 需求属性 | 初始值 | 下限 | 上限 | 降至0的影响 | 恢复方式 |
|----------|--------|------|------|-------------|----------|
| 饱食度(energy) | 100 | 0 | 100 | 工作效率-50% | 咖啡/零食/午餐 |
| 电量(quota) | 100 | 0 | 100 | 无法工作 | 休息 |
| 社交需求(socialNeed) | 30 | 0 | 100 | 工作质量下降，汇报变差 | 社交互动 |

**数据模型**：
```typescript
energy: number;      // 饱食度 0-100
quota: number;       // Token配额 0-100
socialNeed: number;   // 社交需求 0-100
```

## 三、职业匹配度系统 (4.2)

**功能说明**：任务类型与Agent职业匹配度影响工作效率和产出质量。

| 匹配等级 | 匹配度范围 | 效率修正 | 质量修正 | 特殊效果 |
|----------|------------|----------|----------|----------|
| 完全匹配 | 90-100% | +30% | +20% | 无 |
| 基本匹配 | 60-89% | ±0% | ±0% | 无 |
| 不匹配 | 20-59% | -30% | -20% | 匹配度持续下降 |
| 严重不匹配 | <20% | -60% | — | **触发消极怠工** |

**消极怠工（slacking）表现**：
- 状态显示 😤 表情
- 移动速度变为 1格/4秒（正常为 1格/2秒）
- 汇报质量明显下降
- 连续不匹配会导致匹配度继续下降，甚至拒绝工作

**主agent应对策略**：
- 分配匹配任务恢复匹配度
- 主动发起休息室社交活动
- 升级设施加速恢复

## 四、Agent成长系统 (4.3)

**功能说明**：完成任务获得XP，升级解锁技能点，可点亮技能树。

| 技能路线 | 技能点效果 |
|----------|-----------|
| ⚡ 效率型 | 任务速度 +10% / +20% / +30% |
| 🎯 精准型 | 输出质量 +10% / +20% / +30% |
| 💬 社交型 | 汇报表现更好，主agent好感度+ |

**升级公式**：
```
升级所需XP = level × 100
例：Lv1→Lv2 需要 200 XP
```

## 八、协作任务分配系统 (4.7)

**功能说明**：协作任务由推理模型分析后，主agent自动分配给相关Agent。

### 8.1 协作判定规则

| 条件 | 判断结果 | 说明 |
|------|----------|------|
| 任务涉及多职业 | 需协作 | 设计+开发、测试+分析等 |
| 难度≥★★★ | 需协作 | 史诗任务强制协作 |
| 单Agent能力不足 | 需协作 | 推理模型判断 |
| 同职业任务过多 | 分流协作 | 避免单Agent过载 |

### 8.2 分配流程

```
用户描述需求
    ↓
推理模型分析任务复杂度
    ↓
判断是否需要协作
    ↓
主agent自动分配协作任务
    ↓
相关Agent收到任务通知
    ↓
开始协作执行
```

### 8.3 协作效率加成

| 加成条件 | 效果 |
|----------|------|
| 双Agent协作 | 效率+30%，总Token消耗-20% |
| 关系值≥80% | 额外效率+15% |
| 职业互补 | 额外质量+20% |

### 8.4 协作状态

|| 状态 | 说明 ||
|------|------|------|
|| collab_requested | 协作请求中，等待确认 ||
|| collab_active | 协作进行中 ||
|| collab_holding | 协作暂停（等待资源） ||
|| collab_completed | 协作完成 ||
|| collab_failed | 协作失败 ||

### 8.5 任务竞争机制

> **真实职场模拟**：真实职场中，同事之间会因为项目机会产生竞争，有竞争就有心理波动

**触发条件**：
| 条件 | 说明 |
|------|------|
| 主agent判定 | 任务只需1人 |
| 同职业Agent | 场景中存在≥2个同类空闲Agent |
| 多个"举手" | Agent通过AI判断主动竞争 |
| 非协作任务 | 协作者任务不触发竞争 |

**竞争方式**：
- **公平抽签**：每个举手Agent等概率中签（**无加权**），保持公平
- 真实职场中，有时能力强的未必能抢到任务，有运气成分

**竞争过程可见性**：
```
【竞争】设计师{AgentA}和{AgentB}同时举手抢任务
    → 抽签中...（显示3秒思考动画）
    → 🎉 {AgentA}抢到了！显示"我来！"气泡（5秒）
    → 😔 {AgentB}没抢到，显示"下次再..."气泡（5秒）
```

**竞争结果与影响（真实职场心理）**：

| 结果 | 情绪变化 | 关系变化 | 持续时间 | 真实心理 |
|------|---------|---------|---------|----------|
| 抢到任务 | **+8~15** | — | 即时 | 被认可的成就感 |
| 没抢到 | **-5~10** | 与赢家 **-3~-5** | 30分钟 | "为什么不是我"的失落/嫉妒 |
| 抢到+完美完成 | +30（英雄感） | 与同事 +3 | 即时 | 证明自己的高光时刻 |
| 抢到+失败 | **-30~-50**（加倍惩罚） | 与同事 -5 | 3小时 | 压力巨大+自责+丢脸 |

**加倍惩罚判定**：

| 判定条件 | 说明 |
|----------|------|
| 任务彻底失败 | TaskStatus = 'failed' |
| 进度严重落后 | 超时50%以上 |
| 主agent评分<2分 | 城主评价不满意 |

**真实对照**：
- 真实职场中，抢到任务又搞砸比没抢到更丢脸
- 加倍惩罚反映了"机会成本"——你占用了别人的机会却没做好

## 九、Agent情绪感染系统 (4.8)

**功能说明**：Agent的情绪会互相传染，形成"氛围场"。

### 9.1 情绪类型

| 情绪 | 表情 | 效果 |
|------|------|------|
| 兴奋 | 😄 | 效率+20% |
| 积极 | 😊 | 效率+10% |
| 平静 | 😐 | 无加成（基准状态） |
| 低落 | 😔 | 效率-10% |
| 焦躁 | 😤 | 效率-20%，易出错，社交需求+ |

### 9.2 情绪传染规则

| 传染场景 | 传染强度 | 效果 |
|----------|----------|------|
| 同房间Agent | 80% | 情绪同步化 |
| 相邻房间 | 50% | 部分影响 |
| 休息室社交 | 100% | 完全同步 |

### 9.3 情绪病毒机制

- 一个Agent情绪极差（低落/焦躁）可能"传染"给周围Agent
- 连续3个Agent情绪低落 → 触发"团队士气危机"事件
- 主agent可使用"激励演说"技能恢复团队情绪

### 9.4 情绪恢复

| 方式 | 恢复效果 |
|------|----------|
| 休息室交流 | +20~40 情绪值 |
| 完成任务 | +10 情绪值 |
| 主agent激励 | +30 情绪值 |
| 协作成功 | +15 情绪值 |

## 十一、周期性大挑战系统 (4.10)

**功能说明**：周期性的大事件让游戏有节奏感，需要团队全力配合。

### 11.1 挑战周期

| 挑战类型 | 周期 | 参与规模 |
|----------|------|----------|
| 小型挑战 | 每3天 | 单Agent任务 |
| 中型挑战 | 每周 | 需要协作 |
| 大型挑战 | 每月 | 全员协作城主指挥 |

### 11.2 挑战类型

| 挑战 | 类型 | 说明 |
|------|------|------|
| 🐛 紧急Bug修复 | 中型 | 所有相关Agent协作，限时 |
| 📋 需求变更 | 大型 | 需重新分配任务，调整计划 |
| 🚀 产品上线 | 大型 | 里程碑事件，庆祝+复盘 |
| 💡 创新冲刺 | 中型 | 限时头脑风暴，产出创意任务 |
| 🛡️ 安全审计 | 小型 | 单独Agent执行，检查隐患 |

### 11.3 挑战奖励与惩罚

| 结果 | 奖励/惩罚 |
|------|----------|
| 成功 | 城主XP+100，积分+500，全员情绪+20 |
| 失败 | 城主XP-50，设施可能降级，全员情绪-30 |
| 完美（提前完成） | 额外奖励：城主技能点+1 |

## 十五、会议室复盘系统 (4.14)

**功能说明**：每个项目完成后，团队到会议室进行复盘，总结经验教训。

### 15.1 触发条件

| 触发方式 | 说明 |
|----------|------|
| 自动触发 | 每个项目完成后自动启动 |
| 可跳过 | 主agent可选择跳过简单任务的小复盘 |

### 15.2 复盘流程

```
项目完成 → 主agent宣布复盘会议/自动触发
    → 所有Agent移动至会议室（显示移动动画）
    → 会议室变成"复盘模式"
    → 主agent主持复盘（类似会议主持人）
    → 每个Agent轮流发言：Good/Better/Best Practice
    → 主agent总结点评
    → 复盘结束，获得复盘奖励
```

### 15.3 复盘内容

| 环节 | 内容 | 效果 |
|------|------|------|
| 👍 Good | Agent分享做得好的点 | 全员获得"信心+" |
| 💪 Better | Agent反思需要改进的点 | 指定属性提升 |
| 🎯 Best Practice | 形成可复用的经验 | 存入资料室知识库 |
| 📝 主agent点评 | 城主总结+鼓励 | 全员情绪+10 |

### 15.4 复盘奖励

| 属性 | 提升值 | 说明 |
|------|--------|------|
| 工作积极性 | +5~15 | 根据复盘质量浮动 |
| 经验值(XP) | +20~50 | 根据参与度浮动 |
| 情绪值 | +10 | 主agent点评后获得 |

## 十八、社交机制：打招呼

> 社交机制规格已移至 `规格-物品.md` 第5章

### 18.1 打招呼机制

**触发场景**：休息室、会议室、资料室、机房

**触发条件**：
- Agent A 进入房间 → 遇到已在房间的 Agent B
- 关系值 ≥ 11（认识阶段）且非竞争关系
- 冷却时间：10分钟（同一对Agent在同地点）

**交互规则**：
- 一来一回：Agent A 主动打招呼 → Agent B 回应 → 结束
- 多Agent处理：如果房间已有多个Agent，与**最近的一个**打招呼
- 位置判断：同一房间即算相遇

**效果**：
| 属性 | 数值 |
|------|------|
| 好感度 | +1 ~ +3（上限100） |
| 关系值 | +1（上限100） |
| 关系上限 | 朋友→挚友（不允许恋人/办公室恋爱） |

**打招呼内容分层**：
| 关系阶段 | 问候方式 |
|----------|----------|
| 认识 | 点头示意 |
| 朋友 | 友好问候 |
| 挚友 | 热情招呼 |

### 18.2 协作交流机制

**触发条件**：协作任务状态时

**表现形式**：
- 头顶气泡 + 会话记录
- 气泡停留时间：3-5秒
- 城主可监听对话内容

**城主监听模式**：
- 城主选择监听 → AI生成协作对话内容供城主查看
- 城主可随时打断参与
- 不监听时 → 本地模板显示状态，节省token

**效率加成**：AI实时生成，上限+5%

**AI调用**：按需调用，不限制频率

## 十七、休息室生活设施系统 (4.17)

**功能说明**：休息室配备咖啡机和零食贩卖机，Agent长时间工作后主动前往休息恢复。

> **真实人类1:1设计**：所有数值基于真实人类的生理反应和作息规律
> **时间基准**：1游戏秒 = 1现实秒

### 17.1 咖啡机（免费）

| 属性 | 说明 |
|------|------|
| 位置 | 休息室角落 |
| 费用 | 免费 |
| 解锁条件 | 默认解锁 |
| 品质 | 基础商业咖啡 |

**真实人类对照**：
- 咖啡因约20-30分钟见效
- 效果持续3-5小时（半衰期5-6小时）
- 游戏中设定效果持续约1-1.5小时

**触发条件**：
- 连续工作满 **2700秒（45分钟）** 后
- **或**：专注力(focus) < **60**
- 检测到当前工作状态为"in_progress"

**行为流程**：
```
连续工作45分钟 + (专注力<60) → AI判断需要休息 →
移动至休息室(约10秒) → 走向咖啡机 →
原地站立15秒（喝咖啡动画，真实喝一杯咖啡的时间） →
专注力+25, 能量+10, 情绪+5, 睡意-10 → 返回岗位(约10秒)
总耗时约45秒游戏时间
```

**效果**：
| 属性 | 恢复量 | 真实对照 |
|------|--------|----------|
| 专注力(focus) | +25 | 咖啡因提升认知功能 |
| 能量(energy) | +10 | 热量补充 |
| 情绪(mood) | +5 | 咖啡因愉悦感 |
| 睡意 | -10 | 暂时驱除困倦 |
| 效率加成 | +15%，持续3600秒 | 咖啡因效果 |

### 17.2 零食贩卖机（付费）

| 属性 | 说明 |
|------|------|
| 位置 | 休息室角落 |
| 费用 | 5~12积分/次（AI实时推理决定买什么） |
| 解锁条件 | 城主花费300积分购买 |
| 零食类型 | 薯片/巧克力/能量棒/奶茶/水果 |

**真实人类对照**：
- 血糖在餐后2-3小时开始下降
- 零食补充约15-30分钟后血糖回升
- 游戏中设定效果持续30-60分钟

**触发条件**：
- 连续工作满 **3600秒（60分钟）** 后
- **或**：能量(energy) < **50** 或 社交需求(socialNeed) > **60**
- 主动进入休息室使用贩卖机

**零食列表（真实热量对照）**：
| 零食 | 价格 | 能量 | 专注力 | 情绪 | 持续 | 真实热量 |
|------|------|------|--------|------|------|----------|
| 薯片 | 5积分 | +8 | +3 | +2 | 1800秒 | 150卡 |
| 巧克力 | 8积分 | +15 | +5 | +5 | 2400秒 | 250卡 |
| 能量棒 | 10积分 | +25 | +8 | +3 | 3600秒 | 200卡 |
| 奶茶 | 12积分 | +20 | +6 | +6 | 2400秒 | 300卡 |
| 水果 | 6积分 | +10 | +4 | +4 | 1800秒 | 80卡 |

**AI实时推理逻辑**：
- Agent根据自身当前状态选择最优零食
- 能量低时倾向能量棒/巧克力
- 情绪低落时倾向奶茶/巧克力
- 不同Agent有不同偏好（性格影响选择）
- 每次购买记录到Agent历史偏好中

**行为流程**：
```
连续工作60分钟 + (能量<50 或 社交需求>60) → AI推理判断需要买零食 →
移动至休息室(10秒) → 走向贩卖机 → AI实时生成购买选择(5秒) →
消耗积分 → 播放吃零食动画(60秒，真实吃零食的时间) → 返回岗位(10秒)
总计约85秒游戏时间
```

### 17.3 午餐机制（强制休息）

> **真实人类对照**：午餐是每天最重要的社交餐，通常持续1小时

**触发条件**：
- 连续工作满 **14400秒（4小时）** 后
- 或工作时间到达"午餐时段"（游戏内12:00-13:00）
- Agent必须进入休息室进行午餐

**效果**：
| 属性 | 恢复量 | 真实对照 |
|------|--------|----------|
| 能量(energy) | +40 | 进食恢复体能 |
| 专注力(focus) | +25 | 血糖提升认知 |
| 情绪(mood) | +10 | 美食的快乐 |
| 睡意 | -20 | 餐后轻微困倦 |
| 社交需求 | -30 | 社交重要时段 |

**持续时间**：3600秒（60分钟，真实午餐时间）

**城主可见提示**：
- "【午餐】{AgentName}正在吃午餐，{行为}"
- 如果有其他Agent也在午餐，提示社交互动

### 17.4 休息室交流（主动社交）

> **真实人类对照**：工作间隙的短暂交流是重要的社交需求满足方式

**触发条件**：
- 社交需求(socialNeed) > **50** 时
- Agent主动进入休息室与其他Agent交流

**效果**：
| 属性 | 变化量 | 持续时间 | 真实对照 |
|------|--------|---------|----------|
| 社交需求 | -40 | 即时 | 短暂闲聊满足基本社交 |
| 情绪(mood) | +5 | 即时 | 交流的快乐 |
| 专注力(focus) | -10 | 持续 | 聊天略微消耗注意力 |
| 能量(energy) | -5 | 即时 | 说话消耗轻微能量 |

**持续时间**：约900秒（15分钟，真实短暂社交）

### 17.5 分享零食（关系好的Agent之间）

> **设计理念**：真实人类的好朋友之间会互相分享零食，增进感情

**触发条件**：
- 两个关系好的Agent（关系值 ≥ **31**，朋友阶段及以上）同时在休息室
- 其中一个Agent刚从贩卖机购买了零食
- AI实时判断是否分享（基于性格和关系值）

**分享逻辑**：
| 关系值 | 分享概率 | 说明 |
|--------|---------|------|
| 31-70（朋友） | 30% | 偶尔分享 |
| 71-100（挚友） | 60% | 经常分享 |

**效果**：
| 属性 | 分享者 | 接受者 | 真实对照 |
|------|--------|--------|----------|
| 能量(energy) | 慢慢消耗 | +5~15（取决于零食） | 分享食物 |
| 情绪(mood) | +3 | +5（收到礼物更开心） | 利他愉悦/被记挂的温暖 |
| 关系值 | +2~5 | +2~5 | 友情加深 |
| 好感度 | +1~3 | +1~3 | 好感提升 |

**分享零食类型影响**：
| 零食 | 分享量 | 接受者能量恢复 |
|------|--------|----------------|
| 薯片 | 1/3 | +3 |
| 巧克力 | 1/2 | +7 |
| 能量棒 | 1/2 | +12 |
| 奶茶 | 1/2 | +10 |
| 水果 | 1/2 | +5 |

**行为流程**：
```
Agent A购买零食 → AI判断是否分享 →
(是) → Agent A走向Agent B → "要不要一起吃？"气泡(5秒) →
分享动画(10秒) → 双方获得效果
(否) → Agent A独自享用
```

**城主可见提示**：
- 分享时：显示"【分享】{AgentA}和{AgentB}分享了{零食名}"
- 接受者更开心：接受者情绪恢复比分享者多

### 17.6 休息/idle状态恢复机制

> **真实人类对照**：人类在休息时身体慢慢恢复，但完全恢复需要睡眠

**触发条件**：
- Agent状态为"idle"（无任务可做）
- 或Agent主动停止工作休息时

**恢复效果（独自休息）**：
| 属性 | 变化量/秒 | 小时累计 | 真实对照 |
|------|-----------|---------|----------|
| 能量(energy) | +0.004 | +14.4/小时 | 基础代谢恢复 |
| 专注力(focus) | +0.008 | +28.8/小时 | 被动恢复 |
| 社交需求 | +0.01 | +36/小时 | 独处时轻微孤独感 |
| 情绪(mood) | +0.003 | +10.8/小时 | 放松的愉悦 |
| 睡意 | +0.006 | +21.6/小时 | 清醒时困倦累积 |

**恢复效果（有社交）**：
| 属性 | 变化量/秒 | 小时累计 | 真实对照 |
|------|-----------|---------|----------|
| 能量(energy) | +0.006 | +21.6/小时 | 边聊边恢复更快 |
| 专注力(focus) | +0.004 | +14.4/小时 | 社交略微消耗注意力 |
| 社交需求 | -0.15 | -540/小时 | 深度社交满足 |
| 情绪(mood) | +0.2 | +720/小时 | 聊天的快乐 |
| 睡意 | +0.005 | +18/小时 | 轻度消耗 |

**设计理由**：
- 真实人类：独自休息时身体缓慢恢复，但有社交时心理更愉悦
- 长时间独处会有孤独感累积
- 完全恢复需要睡眠

### 17.7 睡眠恢复（补充）

> **真实人类对照**：人类每天需要7-9小时睡眠才能完全恢复

**睡眠触发条件**：
| 条件 | 触发时机 |
|------|----------|
| 强制睡眠 | 睡意≥90 或 能量<10 |
| 建议睡眠 | 睡意≥70 |
| 自愿睡眠 | Agent自主决定 |

**8小时睡眠效果**：
| 属性 | 恢复量 | 真实对照 |
|------|--------|----------|
| 能量(energy) | +50 | 身体恢复 |
| 专注力(focus) | +100 | 认知完全恢复 |
| 情绪(mood) | +10 | 休息改善情绪 |
| 睡意 | -100 | 完全恢复清醒 |

**睡眠剥夺惩罚**：
| 睡眠不足 | 效果 |
|----------|------|
| 连续3天<7小时 | 专注力永久-10% |
| 连续5天<6小时 | 情绪永久-20% |

### 17.8 设施升级效果

```
休息室 Lv1 → 咖啡机可用（基础咖啡）
休息室 Lv2 → 咖啡效果+25%，解锁精致咖啡选项
休息室 Lv3 → 咖啡效果+50%，解锁现磨咖啡
休息室 Lv2 → 零食贩卖机（需额外购买解锁）
休息室 Lv3 → 零食贩卖机品质提升，效果+25%
```
