## 1. 庆功系统

### 1.1 庆功概述

庆功系统让团队在完成重要项目后共享喜悦，增强团队凝聚力。

### 1.2 触发条件

| 触发方式 | 条件 | 说明 |
|----------|------|------|
| 手动触发 | 主agent点击"召开庆功宴" | 任何时候可触发 |
| 自动触发 | 完成里程碑项目 | 大型挑战/协作任务 |
| 自动触发 | 完成史诗任务 | ★★★★难度 |

### 1.3 庆功流程

```
任务完成
    │
    ▼
主agent宣布庆功 / 自动触发
    │
    ▼
所有Agent移动至休息室（显示移动动画）
    │
    ▼
休息室变成"庆功模式"（装饰+特效）
    │
    ▼
每个Agent发表简短的"获奖感言"
    │
    ▼
全员情绪值+20
    │
    ▼
主agent可发表"城主寄语"
    │
    ▼
庆功结束，Agent返回各自岗位
```

### 1.4 庆功效果

| 效果 | 数值 |
|------|------|
| 全员情绪+ | +20 |
| 关系度提升 | +5（所有Agent之间） |
| 城主XP | +15 |
| 社交需求恢复 | -30 |

## 2. 复盘系统

### 2.1 复盘概述

每个项目完成后，团队到会议室进行复盘，总结经验教训。

### 2.2 触发条件

| 触发方式 | 说明 |
|----------|------|
| 自动触发 | 每个项目完成后自动启动 |
| 可跳过 | 主agent可选择跳过简单任务的小复盘 |

### 2.3 复盘类型

| 类型 | 适用场景 | 奖励倍率 |
|------|----------|----------|
| 快速复盘 | 简单任务 | x0.5 |
| 标准复盘 | 普通项目 | x1.0 |
| 深度复盘 | 里程碑/大型挑战 | x2.0 |

### 2.4 复盘流程

```
项目完成
    │
    ▼
主agent宣布复盘会议 / 自动触发
    │
    ▼
所有Agent移动至会议室（显示移动动画）
    │
    ▼
会议室变成"复盘模式"
    │
    ▼
主agent主持复盘（类似会议主持人）
    │
    ▼
每个Agent轮流发言：Good/Better/Best Practice
    │
    ▼
主agent总结点评
    │
    ▼
复盘结束，获得复盘奖励
```

### 2.5 复盘内容

| 环节 | 内容 | 效果 |
|------|------|------|
| 👍 Good | Agent分享做得好的点 | 全员获得"信心+" |
| 💪 Better | Agent反思需要改进的点 | 指定属性提升 |
| 🎯 Best Practice | 形成可复用的经验 | 存入资料室知识库 |
| 📝 主agent点评 | 城主总结+鼓励 | 全员情绪+10 |

### 2.6 复盘奖励

| 属性 | 提升值 | 说明 |
|------|--------|------|
| 工作积极性 | +5~15 | 根据复盘质量浮动 |
| 经验值(XP) | +20~50 | 根据参与度浮动 |
| 情绪值 | +10 | 主agent点评后获得 |
| 社交需求 | -20 | 团队交流消耗社交需求 |

## 3. 庆功/复盘状态

### 3.1 状态定义

```typescript
type CelebrationState = {
  status: 'idle' | 'moving' | 'celebrating' | 'finished';
  type: 'celebration' | 'retrospective' | null;
  participants: string[];  // 参与者Agent ID列表
  currentPhase: 'dialogue' | 'speech' | 'summary' | null;
  startedAt: number;
  dialogues: CelebrationDialogue[];
};

interface CelebrationDialogue {
  agentId: string;
  text: string;
  timestamp: number;
}
```

### 3.2 状态转换

```
idle → moving → celebrating → finished → idle
                 ↑
            也可以从retrospective进入
```

## 5. 庆功/复盘与社交的关系

### 5.1 社交效果

| 活动 | 关系值变化 | 情绪变化 |
|------|------------|----------|
| 庆功宴 | +5（所有人之间） | +20 |
| 复盘会议 | +2（参与者之间） | +10 |

### 5.2 触发优先级

| 优先级 | 事件 |
|--------|------|
| 1 | 庆功宴 + 复盘（同时进行） |
| 2 | 仅庆功宴 |
| 3 | 仅复盘 |
| 4 | 跳过（简单任务） |
