# Hermes数字工作室 — 社交系统详细设计

> **文档版本**：v2.0（真实人类1:1模拟版）
> **设计理念**：所有数值与真实人类社交行为1:1对应
> **时间基准**：1游戏秒 = 1现实秒
> **状态**：规划中

---

## 1. 社交机制概述

### 1.1 社交类型

| 社交类型 | 触发方式 | 真实时长 | 说明 |
|----------|----------|---------|------|
| 打招呼 | 自动触发 | 30秒 | 真实职场中的点头之交 |
| 协作交流 | 协作任务 | 实时 | 工作中实时对话 |
| 短暂闲聊 | 主动社交 | 15分钟 | 工作间隙的咖啡聊 |
| 深度交流 | 主动社交 | 1-2小时 | 真正的情感连接 |
| 分享零食 | 主动社交 | 5分钟 | 朋友间的小确幸 |
| 午餐社交 | 强制午餐 | 1小时 | 最重要的社交餐 |

### 1.2 关系阶段

| 阶段 | 关系值范围 | 称呼 | 解锁内容 |
|------|------------|------|----------|
| 陌生 | 0-10 | 陌生人 | 无 |
| 认识 | 11-30 | 同事 | 基础打招呼 |
| 朋友 | 31-70 | 朋友 | 友好问候、协作邀请、分享零食 |
| 挚友 | 71-100 | 挚友 | 热情招呼、深度协作、主动分享 |

> **关系上限**：朋友 → 挚友（不允许恋人/办公室恋爱）

## 2. 打招呼机制

### 2.1 触发规则

| 要素 | 说明 |
|------|------|
| **触发场景** | 休息室、会议室、资料室、机房 |
| **触发条件** | Agent A 进入房间 → 遇到已在房间的 Agent B |
| **关系要求** | 关系值 ≥ 11（认识阶段） |
| **竞争关系** | 同职业Agent存在竞争，不触发打招呼 |
| **冷却时间** | 3600秒（60分钟，同一对Agent在同地点） |
| **多Agent处理** | 如果房间已有多个Agent，与**最近的一个**打招呼 |
| **位置判断** | 同一房间即算相遇 |

### 2.2 交互规则

- **一来一回**：Agent A 主动打招呼 → Agent B 回应 → 结束
- **状态互斥**：打招呼状态与协作交流状态互斥
- **优先级**：协作交流 > 打招呼
- **气泡停留**：5秒（真实对话时间）

### 2.3 效果

| 属性 | 数值 | 上限 | 真实对照 |
|------|------|------|----------|
| 好感度 | +1~3 | 100 | 见面多了一个熟人 |
| 关系值 | +1 | 100 | 点头之交 |
| 社交需求 | -15 | — | 短暂的社交满足 |

### 2.4 打招呼内容生成

> **说明**：打招呼内容由推理模型根据 Agent 的性格、职业、当前状态和关系阶段自动实时生成，无需配置固定内容。

**生成要素**：性格、职业、关系阶段、当前场景、近期状态

**打招呼内容分层**：

| 关系阶段 | 问候方式 | 真实时长 |
|----------|----------|----------|
| 认识（11-30） | 点头示意，简单寒暄 | 10-30秒 |
| 朋友（31-70） | 友好问候，关心近况 | 30-60秒 |
| 挚友（71-100） | 热情招呼，分享趣事 | 1-2分钟 |

### 2.5 示例打招呼内容

#### 认识阶段（关系值 11-30）

```
Agent A: "你好。"
Agent B: "嗯，你好。"
```

#### 朋友阶段（关系值 31-70）

```
Agent A: "嘿，今天怎么样？工作还顺利吗？"
Agent B: "还不错，你呢？最近在做什么项目？"
```

#### 挚友阶段（关系值 71-100）

```
Agent A: "哇！你也在这儿！好久不见！最近怎么样？"
Agent B: "哈哈！正好想找你聊聊！走，去喝杯咖啡？"
```

## 3. 协作交流机制

### 3.1 触发条件

- Agent 处于协作任务状态
- 协作任务进行中

### 3.2 表现形式

> **说明**：协作交流内容由推理模型实时生成，**按需调用AI，不限制频率**。
> 城主可选择监听或参与协作交流。

**生成要素**：

| 要素 | 说明 |
|------|------|
| 任务类型 | 设计/编码/测试/分析任务 |
| Agent关系 | 关系阶段影响交流语气 |
| 任务进度 | 刚开始/进行中/遇到困难/即将完成 |
| 困难程度 | 简单/一般/困难/卡点 |
| Agent性格 | 影响表达方式和用词 |

| 要素 | 说明 |
|------|------|
| **头顶气泡** | 显示当前对话内容 |
| **气泡停留** | 3-5秒后消失 |
| **会话记录** | 保存在协作日志中 |
| **效率加成** | AI实时生成，上限+5% |

**城主监听模式**：
- 城主选择监听 → AI生成协作对话内容供城主查看
- 城主可随时打断参与
- 不监听时 → 本地模板显示状态，节省token

### 3.3 状态互斥

| 状态 | 说明 |
|------|------|
| 协作交流中 | 不触发打招呼 |
| 打招呼中 | 不触发协作交流 |

## 4. 自由交流机制

### 4.1 触发条件

- Agent 处于空闲状态（idle）
- 社交需求 ≥ **50**（开始感到孤独）
- 附近有其他Agent

### 4.2 交流内容

- 基于Agent性格生成
- 可使用已解锁的梗
- 城主可观察交流内容

### 4.3 主agent可介入

- 主agent可随时发起对话
- 主agent可观察Agent间的自由交流
- 主agent可给Agent建议

### 4.4 分享零食机制

> **设计理念**：真实人类的好朋友之间会互相分享零食，增进感情

**触发条件**：
- 两个关系好的Agent（关系值 ≥ **31**，朋友阶段及以上）同时在休息室
- 其中一个Agent刚从贩卖机购买了零食
- AI实时判断是否分享（基于性格和关系值）

**分享概率**：
| 关系值 | 分享概率 | 说明 |
|--------|---------|------|
| 31-70（朋友） | 30% | 偶尔分享 |
| 71-100（挚友） | 60% | 经常分享 |

**分享效果（真实对照）**：
| 属性 | 分享者 | 接受者 | 真实对照 |
|------|--------|--------|----------|
| 能量 | 慢慢消耗 | +5~15（取决于零食） | 分享食物 |
| 情绪 | +3 | +5（收到礼物更开心） | 利他愉悦/被记挂的温暖 |
| 关系值 | +2~5 | +2~5 | 友情加深 |
| 好感度 | +1~3 | +1~3 | 好感提升 |

## 5. 情绪感染

### 5.1 感染强度

| 场景 | 传染强度 | 真实对照 |
|------|----------|----------|
| 同房间Agent | 80% | 办公室氛围传染 |
| 相邻房间 | 50% | 隔着墙也能感受到 |
| 休息室社交 | 100% | 面对面完全同步 |

### 5.2 感染规则

- 高情绪Agent可提升周围低情绪Agent的情绪
- 负面情绪同样会传染
- 休息室社交时情绪感染最强
