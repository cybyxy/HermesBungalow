## 3. 成就系统设计

### 3.1 成就数据结构

```typescript
interface Achievement {
  id: string;
  name: string;
  description: string;
  icon: string;
  category: 'milestone' | 'collab' | 'efficiency' | 'social' | 'random' | 'citylord';
  rarity: 'common' | 'rare' | 'legendary';

  // 解锁条件
  condition: AchievementCondition;
  progress?: number;     // 当前进度
  target?: number;       // 目标值

  // 奖励
  reward: {
    points?: number;
    xp?: number;
    skill?: string;
    item?: string;
    buff?: string;
  };

  // 状态
  unlocked: boolean;
  unlockedAt?: number;
}

interface AchievementCondition {
  type: string;          // 条件类型
  target?: string;       // 目标对象
  value?: number;        // 目标数值
  count?: number;        // 计数
}
```

### 3.2 成就检查算法

```python
def check_achievements(game_state: GameState):
    """
    每秒检查成就解锁情况
    """
    for achievement in ALL_ACHIEVEMENTS:
        if achievement.unlocked:
            continue

        condition = achievement.condition

        if condition.type == 'first_task_complete':
            if game_state.tasks_completed >= 1:
                unlock_achievement(achievement)

        elif condition.type == 'continuous_perfect_match':
            if game_state.consecutive_perfect_matches >= 10:
                unlock_achievement(achievement)

        elif condition.type == 'relationship_value':
            agent = get_agent(condition.target)
            if agent.relationship_value >= condition.value:
                unlock_achievement(achievement)

        # ... 其他条件类型
```

### 3.3 成就解锁流程

```
游戏事件发生
    │
    ▼
检查成就条件
    │
    ▼
条件满足？
    │
 Yes │
    ▼
解锁成就
    │
    ▼
显示成就弹窗
    │
    ▼
发放奖励
    │
    ▼
更新成就列表
```
