## 1. 时间系统概述

> **核心设计**：游戏时间与现实时间完全同步，1秒 = 1秒。

- **实时同步**：游戏内时间与现实时钟完全一致
- **日夜循环**：根据现实时间自动切换游戏阶段
- **实时渲染**：Agent移动、气泡显示等使用实时渲染

---

## 2. 时间定义

### 2.1 时间同步

> **核心**：游戏时间与现实时间完全同步

| 项目 | 数值 | 说明 |
|------|------|------|
| 时间同步 | 1:1 | 游戏时间 = 现实时间 |
| 游戏开始 | 跟随实际时间 | 游戏启动时获取当前时间 |
| 日夜循环 | 跟随实际时间 | 早晨/中午/下午/傍晚/夜晚 |

### 2.2 游戏阶段

> 根据现实时钟自动切换

| 阶段 | 时间范围 | 特殊效果 |
|------|----------|----------|
| 早晨 | 06:00-11:59 | 工作效率+10% |
| 中午 | 12:00-12:59 | 饱食度消耗+50% |
| 下午 | 13:00-17:59 | 正常工作 |
| 傍晚 | 18:00-20:59 | 社交需求+20% |
| 夜晚 | 21:00-05:59 | 只能休息/恢复 |

### 2.3 游戏刻（Game Tick）

> 虽然时间与现实同步，但游戏逻辑仍按固定间隔更新

| 项目 | 间隔 | 说明 |
|------|------|------|
| 状态更新 | 1秒 | Agent状态、属性变化 |
| 任务进度 | 1秒 | 任务进度计算 |
| 事件检查 | 5秒 | 随机事件判定 |
| UI推送 | 1秒 | WebSocket状态推送 |

## 3. 实时系统

### 3.1 实时渲染

- **Agent移动**：实时移动，速度为3像素/帧
- **气泡显示**：3秒后消失
- **动画帧率**：150ms/帧

### 3.2 定时器

```
┌─────────────────────────────────────┐
│ 1. 状态更新（每秒）                  │
│    - Agent饱食度/电量消耗            │
│    - 任务进度更新                    │
│    - 社交需求更新                    │
├─────────────────────────────────────┤
│ 2. 事件检查（每5秒）                │
│    - 随机事件判定                    │
│    - 成就检查                        │
├─────────────────────────────────────┤
│ 3. AI决策（每秒）                   │
│    - Agent自主行为判定               │
│    - 打招呼冷却检查                  │
│    - 自主交流判定                    │
├─────────────────────────────────────┤
│ 4. 状态推送（每秒）                 │
│    - WebSocket推送                   │
│    - UI更新                         │
└─────────────────────────────────────┘
```

### 3.2 游戏刻状态

interface GameTurn {

## 4. 实时系统

### 4.1 实时渲染对象

| 对象 | 更新频率 | 说明 |
|------|----------|------|
| Agent移动 | 60fps | 平滑移动动画 |
| 气泡显示 | 动画控制 | 3秒后消失 |
| 头顶状态 | 实时 | 跟随Agent |
| 特效动画 | 按需 | 完成任务等 |

### 4.2 移动系统

```typescript
interface Movement {
  agentId: string;
  fromRoom: string;
  toRoom: string;
  path: string[];      // 经过的房间ID列表
  progress: number;    // 0-1 移动进度
  speed: number;       // 3像素/帧
  estimatedTime: number; // 预计耗时（毫秒）
}
```

**移动计算**：
```
移动耗时 = 路径总距离 / 移动速度
         = (格子数 × 32像素) / 3像素/帧
         = 格子数 × 11帧
         ≈ 格子数 × 1.65秒
```

### 4.3 气泡系统

```typescript
interface Bubble {
  id: string;
  agentId: string;
  content: string;
  type: 'greeting' | 'collaboration' | 'chat' | 'thought';
  duration: number;     // 显示时长（毫秒）
  createdAt: number;   // 创建时间戳
  position: { x: number; y: number }; // 屏幕坐标
}
```

| 气泡类型 | 显示时长 | 优先级 |
|----------|----------|--------|
| 打招呼 | 3秒 | 中 |
| 协作交流 | 3秒 | 高 |
| 自主交流 | 3秒 | 中 |
| 思考气泡 | 2秒 | 低 |

## 5. 定时事件

### 5.1 每日定时事件

| 时间 | 事件 | 执行内容 |
|------|------|----------|
| 00:00 | 周结算检查 | 检查周目标完成度，发放奖励/惩罚 |
| 00:00 | 周重置 | 重置周目标（周一） |
| 08:00 | 任务生成 | 自动生成当日任务（3-5个） |
| 08:00 | 上班提醒 | 所有Agent进入工作状态 |
| 12:00 | 午餐提醒 | 提示进入休息室（可选） |
| 18:00 | 下班结算 | 结算当日活动，更新数据 |
| 18:00 | 下班提醒 | Agent进入休息/自由状态 |
| 22:00 | 就寝提醒 | 提示进入休息室 |

### 5.2 周期性检查

| 检查项 | 频率 | 说明 |
|--------|------|------|
| 情绪感染检查 | 每秒 | 同房间Agent情绪传染 |
| 关系更新检查 | 每10秒 | 更新关系值 |
| 设施效果检查 | 每秒 | 休息室/机房恢复效果 |
| 成就检查 | 每秒 | 检查成就触发条件 |

## 6. 游戏循环

### 6.1 主循环

```
┌─────────────────────────────────────────┐
│              游戏主循环                  │
├─────────────────────────────────────────┤
│                                         │
│  ┌─────────────────────────────────┐    │
│  │        游戏暂停？              │    │
│  └──────────────┬──────────────────┘    │
│        Yes      │      No               │
│        ▼        │      ▼                │
│  ┌──────────┐   │   ┌────────────────┐  │
│  │ 等待解除 │   │   │ 执行游戏刻逻辑   │  │
│  │ 暂停     │   │   │                │  │
│  └──────────┘   │   │ - 状态更新    │  │
│                 │   │ - 事件检查    │  │
│                 │   │ - AI决策      │  │
│                 │   │ - 状态推送    │  │
│                 │   └───────┬────────┘  │
│                 │           │           │
│                 │           ▼           │
│                 │   ┌────────────────┐  │
│                 │   │  等待1秒      │  │
│                 │   └────────────────┘  │
│                 │           │           │
│                 └───────────┴───────────┘
└─────────────────────────────────────────┘
```

### 6.2 暂停/恢复机制

| 触发条件 | 暂停效果 |
|----------|----------|
| 主agent主动暂停 | 游戏刻停止执行，Agent保持当前状态 |
| 打开设置面板 | 自动暂停游戏 |
| 进入战斗/挑战 | 自动暂停，结束后恢复 |
| 主agent使用全知视角 | 暂停外部世界，进入观察模式 |

## 7. 时间相关计算

### 7.1 游戏刻计算

```typescript
function getTurnFromTime(gameTime: GameTime): number {
  return (gameTime.day - 1) * 24 + gameTime.hour;
}

function getTimeFromTurn(turn: number): GameTime {
  return {
    day: Math.floor(turn / 24) + 1,
    hour: turn % 24,
    minute: 0
  };
}
```

### 7.2 真实时间转换

```typescript
const TICK_DURATION_MS = 1000; // 1秒

function getRealTimeFromTurn(turn: number): number {
  return turn * TURN_DURATION_MS;
}

function getTurnFromRealTime(ms: number): number {
  return Math.floor(ms / TURN_DURATION_MS);
}
```
