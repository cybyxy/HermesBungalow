## 1. 新手引导概述

### 1.1 引导目标

帮助玩家（主agent）快速理解游戏核心玩法：
1. 了解基地布局
2. 学习配置Agent（通过配置Hermes Profile）
3. 学会分配任务
4. 理解社交机制
5. 掌握城主技能

### 1.2 引导流程

| 步骤 | 内容 | 时长 |
|------|------|------|
| 1 | 欢迎与角色介绍 | 1分钟 |
| 2 | 基地导览 | 2分钟 |
| 3 | 配置第一个Agent | 2分钟 |
| 4 | 第一个任务 | 2分钟 |
| 5 | 社交与打招呼 | 1分钟 |
| 6 | 城主技能 | 1分钟 |
| 7 | 自由探索 | - |

## 3. 引导状态管理

### 3.1 引导状态

```typescript
interface GuideState {
  currentStep: number;
  completed: boolean;
  steps: {
    [stepId: string]: {
      completed: boolean;
      skipped: boolean;
      completedAt?: number;
    };
  };
  // 步骤数据
  stepData: {
    firstTaskAssigned?: boolean;
    firstGreeting?: boolean;
    firstSkillUsed?: boolean;
  };
}
```

### 3.2 引导步骤定义

```typescript
const GUIDE_STEPS = [
  {
    id: 'welcome',
    title: '欢迎',
    description: '介绍游戏和角色',
    targetElement: null,
    condition: () => true,
  },
  {
    id: 'tour',
    title: '基地导览',
    description: '认识基地布局',
    targetElement: '#activity-space',
    condition: () => true,
  },
  {
    id: 'recruit',
    title: '配置Agent',
    description: '学习配置Hermes Profile添加Agent',
    targetElement: null,
    condition: () => true,
  },
  {
    id: 'first_task',
    title: '分配任务',
    description: '完成第一个任务分配',
    targetElement: '#task-panel',
    condition: (state) => !state.stepData.firstTaskAssigned,
  },
  {
    id: 'observe_work',
    title: '观察工作',
    description: '观察Agent工作状态',
    targetElement: '#agent-list',
    condition: (state) => state.stepData.firstTaskAssigned,
  },
  {
    id: 'social_greeting',
    title: '社交',
    description: '体验打招呼机制',
    targetElement: '#rest-room',
    condition: (state) => !state.stepData.firstGreeting,
  },
  {
    id: 'skill',
    title: '城主技能',
    description: '使用城主技能',
    targetElement: '#skill-button',
    condition: (state) => !state.stepData.firstSkillUsed,
  },
  {
    id: 'complete',
    title: '完成',
    description: '新手引导结束',
    targetElement: null,
    condition: (state) => state.stepData.firstSkillUsed,
  },
];
```

## 5. 跳过机制

### 5.1 跳过条件

| 条件 | 说明 |
|------|------|
| 玩家主动跳过 | 任何步骤可点击"跳过" |
| 快速跳过 | 连续点击3次自动跳过 |
| 超时跳过 | 3分钟无操作自动跳过 |

### 5.2 跳过记录

```typescript
// 跳过某步骤后，记录到状态
guideState.steps[stepId] = {
  completed: false,
  skipped: true,
  completedAt: Date.now(),
};
```
