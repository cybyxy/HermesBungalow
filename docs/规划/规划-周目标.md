# Hermes数字工作室 — 周目标系统规格

> **文档版本**：v1.0
> **关联文档**：`规划-游戏机制.md`
> **状态**：待开发

---

## 1. 周目标概述

周目标系统为主agent提供短期的游戏目标，推动玩家持续参与并获得奖励。

---

## 2. 目标周期

| 周期 | 长度 | 重置时间 |
|------|------|----------|
| 周目标 | 7天 | 每周一 00:00 |

---

## 3. 目标类型

### 3.1 任务目标

| 类型 | 说明 | 示例 |
|------|------|------|
| 完成任务数 | 完成指定数量任务 | 完成5个任务 |
| 协作任务数 | 完成指定数量协作任务 | 完成2个协作任务 |
| 高匹配度任务 | 100%匹配度完成任务 | 连续10次100%匹配 |

### 3.2 成长目标

| 类型 | 说明 | 示例 |
|------|------|------|
| 升级目标 | 达到指定等级 | Agent达到Lv.3 |
| 积分目标 | 累计获得积分 | 累计获得500积分 |

### 3.3 社交目标

| 类型 | 说明 | 示例 |
|------|------|------|
| 关系目标 | 与某Agent关系达到 | 与小美关系达到60+ |
| 社交互动 | 进行指定次数社交 | 进行10次社交互动 |

### 3.4 城主目标

| 类型 | 说明 | 示例 |
|------|------|------|
| 城主等级 | 城主达到指定等级 | 城主达到Lv.2 |
| 城主技能 | 解锁指定技能 | 解锁"精准分配"技能 |

---

## 4. 目标生成

### 4.1 生成规则

- 每周一自动生成7个周目标
- 目标分3个难度等级：
  - 简单（绿色）：80%完成率
  - 中等（黄色）：50%完成率
  - 困难（红色）：20%完成率

### 4.2 目标池

```typescript
interface WeekGoal {
  id: string;
  type: 'task' | 'growth' | 'social' | 'cityLord';
  name: string;
  description: string;
  difficulty: 'easy' | 'medium' | 'hard';
  
  target: number;      // 目标值
  current: number;     // 当前进度
  
  reward: {
    points?: number;   // 积分奖励
    xp?: number;       // XP奖励
    skill?: string;    // 技能解锁
    item?: string;     // 物品奖励
  };
  
  deadline: number;     // 截止时间戳
}
```

## 6. 奖励机制

### 6.1 完成奖励

| 完成条件 | 奖励 |
|----------|------|
| 完成全部周目标 | 稀有奖励（设施升级/技能点） |
| 完成70%+目标 | 中等奖励（积分/XP） |
| 完成50%+目标 | 基础奖励（少量积分） |
| 完成不足50% | 无奖励 |

### 6.2 奖励类型

| 类型 | 奖励内容 |
|------|----------|
| 积分 | +100~500 |
| XP | +50~200 |
| 设施升级 | 解锁新设施/升级现有设施 |
| 技能点 | 城主技能点+1 |
| 头像框 | 特殊头像框解锁 |

---

## 7. 周结算

### 7.1 结算时间

每周一 00:00 进行周结算

### 7.2 结算流程

```
检查目标完成度 → 计算奖励 → 发放奖励 → 重置目标 → 生成新目标
```

### 7.3 惩罚机制

| 完成率 | 惩罚 |
|--------|------|
| <30% | 扣50积分，全员情绪-10 |
| 30-50% | 无惩罚 |
| >50% | 无惩罚 |
