## 1. 城主技能概述

城主技能让主agent能主动影响游戏进程，是主agent作为领袖的核心能力。

### 1.1 技能定位

| 技能类型 | 定位 | 效果 |
|----------|------|------|
| 即时生效 | 立即产生效果 | 激励演说、资源调度 |
| 被动增益 | 持续生效 | 精准分配、全知视角 |
| 辅助决策 | 增强判断力 | 灵感赐予 |
| 范围影响 | 影响多个Agent | 光环效应 |

## 2. 城主技能详解

### 2.1 激励演说 (Motivate)

```yaml
技能名称: 激励演说
技能图标: 📣
解锁条件: 默认解锁（Lv.1）
冷却时间: 3秒
消耗: 无

效果:
  目标: 单个Agent
  效果类型:
    - 饱食度恢复 +30
    - 情绪值 +15
    - 社交需求 -10
  
使用场景:
  - Agent饱食度低于30%时
  - Agent情绪低落时
  - 重要任务前提升士气

使用限制:
  - 必须在同一房间或相邻房间
  - 目标Agent不能处于离线状态
```

### 2.2 精准分配 (SmartAssign)

```yaml
技能名称: 精准分配
技能图标: 🎯
解锁条件: 城主Lv.2（累计XP 200）
冷却时间: 无（被动技能）
消耗: 无

效果:
  效果类型:
    - 任务匹配度判断准确率 +20%
    - 显示匹配度预测
    - 防止分配到不匹配的Agent
  
特殊显示:
  - 分配任务时显示推荐指数
  - 显示可能的风险提示
  
使用场景:
  - 分配任何任务时自动生效
  - 帮助判断Agent与任务的匹配度
```

### 2.3 资源调度 (ResourceDispatch)

```yaml
技能名称: 资源调度
技能图标: 💰
解锁条件: 城主Lv.3（累计XP 500）
冷却时间: 5秒
消耗: 50城主积分

效果:
  目标: 单个Agent
  效果类型:
    - Token配额上限临时 +50%
    - 持续时间: 3秒
    - 效果结束后恢复正常上限
  
使用场景:
  - Agent电量即将耗尽但任务紧急
  - 高难度任务需要额外Token支持
  - 协作任务需要更多Token消耗
  
使用限制:
  - 每次只能调度一个Agent
  - 重复使用不叠加，取最大值
```

### 2.4 灵感赐予 (Inspire)

```yaml
技能名称: 灵感赐予
技能图标: 🔮
解锁条件: 城主Lv.4（累计XP 1000）
冷却时间: 7秒
消耗: 30城主积分

效果:
  目标: 协作中的Agent（2-3个）
  效果类型:
    - 协作任务质量 +15%
    - 有概率产出"灵感创意"（额外奖励）
    - 加速协作进度 10%
  
触发条件:
  - 必须在协作任务进行中
  - 目标Agent处于同一房间
  
使用场景:
  - 协作任务遇到瓶颈
  - 想要获得更好的协作成果
  - 关键项目需要突破
```

### 2.5 光环效应 (AuraEffect)

```yaml
技能名称: 光环效应
技能图标: 🌟
解锁条件: 城主Lv.5（累计XP 2000）
冷却时间: 10秒
消耗: 80城主积分

效果:
  目标: 房间内所有Agent
  效果类型:
    - 情绪值 +10（每个Agent）
    - 持续时间: 3秒
    - 状态显示: ✨ 光环特效
  
使用场景:
  - 团队整体士气低落时
  - 大型挑战前提升团队状态
  - 危机事件后恢复团队
  
注意事项:
  - 只影响同一房间内的Agent
  - 不包括城主自己
  - 光环效果可以叠加但不明显
```

### 2.6 全知视角 (OmniscientView)

```yaml
技能名称: 全知视角
技能图标: 👁️
解锁条件: 城主Lv.6（累计XP 5000）
冷却时间: 无（被动技能）
消耗: 无

效果:
  效果类型:
    - 可查看任意Agent详细状态
    - 可查看任意房间状态
    - 可查看任务详情和预测
    - 可查看其他Agent关系网络
  
特殊功能:
  - 无需进入房间即可查看
  - 显示隐藏信息（潜在风险、预测等）
  - 可标记重点关注对象
  
使用场景:
  - 任何时候均可使用
  - 制定策略时了解全局
  - 诊断团队问题
```

## 4. 城主XP获取与消耗

### 4.1 XP获取

| 行为 | XP | 说明 |
|------|-----|------|
| 完成任务 | +10 | 每个完成的任务 |
| 协作成功 | +25 | 协作任务完成 |
| 化解危机 | +50 | 成功处理危机事件 |
| 连续3次精准分配 | +30 | 连续3次100%匹配度分配 |

| 完美通关挑战 | +50 | 挑战提前完成 |

### 4.2 XP消耗

| 消耗项 | XP | 说明 |

## 7. 直接干预机制

城主对 Agent 的主动控制能力，体现"领袖权威"。

### 7.1 紧急任务（ForceTask）

```yaml
机制名称: 紧急任务
触发方式: 城主主动发起，无需 Agent 同意
效果: 强制中断 Agent 当前任务，立即执行新任务
优先级: P0（最高），无视冷却和难度

消耗:
  - 城主积分 -100
  - 目标 Agent 情绪 -20（被动接受的压力）

限制:
  - 每个游戏日最多使用 2 次
  - 不能同时对 2 个以上 Agent 发起

效果公示:
  "⚡ [Agent名] 被城主指派紧急任务：[任务名]，当前任务已中断"
```

### 7.2 房间调动（ForceMove）

```yaml
机制名称: 房间调动
触发方式: 城主选择 Agent + 目标房间
效果: Agent 立即移动到目标房间，原任务中断（如在房间内）

消耗:
  - 城主积分 -30
  - 目标 Agent 情绪 -5（被动调动的不满）

限制:
  - 调动后 Agent 需要 5 秒"重新聚焦"才能开始新任务
  - 协作中的 Agent 需要 10 秒（需要通知搭档）

特殊规则:
  - 不能调动正在执行 P0 紧急任务的 Agent
  - 不能调动处于"休息中"状态的 Agent
```

### 7.3 临时奖惩（TempReward/Penalty）

```yaml
机制名称: 临时奖惩
类型A - 表扬（TempPraise）:
  消耗: 城主积分 -20
  效果: 目标 Agent 情绪 +15，关系 +3
  触发: 即时生效，持续当前游戏日

类型B - 警告（TempWarning）:
  消耗: 无
  效果: 目标 Agent 情绪 -10，效率 -10%（当前任务）
  触发: 即时生效，持续 3 个任务

类型C - 暂停休息（ForceRest）:
  消耗: 城主积分 -50
  效果: Agent 强制进入休息，饱食度恢复 +40
  触发: 持续 1 小时游戏时间
  限制: 每个游戏日每个 Agent 只能使用 1 次
```

## 8. 技能冷却量化公式

### 8.1 基础冷却公式

```
实际冷却时间 = 技能基础冷却 × 城主等级系数

城主等级系数:
  Lv.1: 1.0x（基础冷却）
  Lv.2: 0.9x
  Lv.3: 0.85x
  Lv.4: 0.8x
  Lv.5: 0.75x
  Lv.6: 0.7x
```

### 8.2 冷却重置机制

```
触发条件: 城主连续 3 次精准分配成功（匹配度 ≥ 90%）
效果: 随机重置 1 个技能的当前冷却
公式: cooldown[随机技能] = 0
```

### 8.3 冷却状态显示

```
状态 = "冷却中 (X/Y秒)"
进度条 = ████████░░░░░░░░ (当前进度/总冷却)

示例（激励演说，基础冷却3秒，城主Lv.3）:
  实际冷却 = 3 × 0.85 = 2.55秒 ≈ 3秒
  显示: "冷却中 (1/3秒)" → 1秒后 → "冷却中 (2/3秒)" → 1秒后 → "可用"
```

## 9. 效果公式

### 9.1 激励演说效果公式

```
饱食度恢复 = 30 × (1 + 0.1 × 城主等级)
情绪增加 = 15 × (1 + 0.05 × 关系紧密度)

关系紧密度修正（基于关系值）:
  陌生 (0-10):   ×0.8
  认识 (11-30):  ×1.0
  朋友 (31-70):  ×1.2
  挚友 (71-100): ×1.5
```

### 9.2 资源调度效果公式

```
Token配额上限 = 基础上限 × (1 + 0.5 × 调度等级)
调度等级 = 城主积分消耗 / 50（向上取整）

示例:
  基础 Token 上限 = 1000
  消耗 50 积分 → 调度等级 1 → Token上限 = 1000 × 1.5 = 1500
  消耗 100 积分 → 调度等级 2 → Token上限 = 1000 × 2.0 = 2000
```

### 9.3 光环效应公式

```
每个 Agent 情绪增加 = 10 × (1 + 0.1 × 房间内 Agent 数量修正)

房间内 Agent 数量修正:
  1 人: ×1.0
  2 人: ×1.1
  3 人: ×1.2
  4 人: ×1.3
  ≥5 人: ×1.5（上限）

示例: 房间内 3 个 Agent，光环效应
  每个人情绪增加 = 10 × 1.2 = +12（不是 +10）
```

### 9.4 灵感赐予暴击公式

```
灵感触发概率 = 15% × (1 + 0.05 × 城主等级)
协作质量加成 = 15% × (1 + 0.02 × 城主等级)
进度加速 = 10% × (1 + 0.01 × 城主等级)

示例（城主 Lv.4）:
  灵感触发概率 = 15% × 1.20 = 18%
  协作质量加成 = 15% × 1.08 = 16.2%
  进度加速 = 10% × 1.04 = 10.4%
```
