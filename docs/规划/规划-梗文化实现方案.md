## 1. 梗文化概述

### 1.1 梗的定义

Agent在工作过程中产生的独特口头禅和个人风格，增加角色魅力和个性。

### 1.2 梗的来源

| 来源 | 说明 | 示例 |
|------|------|------|
| 工作习惯 | 每次任务都会说的口头禅 | "命名强迫症犯了" |
| 职业特征 | 角色自带的职业梗 | "让我查一下数据" |
| 协作经历 | 协作中产生的专属梗 | 协作成功后解锁 |
| 随机触发 | 特定条件下触发 | 完成困难任务后 |

## 2. 梗的配置

### 2.1 梗数据结构

```typescript
interface Meme {
  id: string;
  name: string;              // 梗名称
  text: string;              // 梗文本
  agentId: string;           // 所属Agent
  source: 'work_habit' | 'role' | 'collab' | 'random';
  rarity: 'common' | 'rare' | 'legendary';
  unlockCondition: MemeCondition;
  displayStyle: 'normal' | 'italic' | 'bold';
  firstUsedAt?: number;     // 首次使用时间
}

interface MemeCondition {
  type: 'task_count' | 'collab_count' | 'relationship' | 'achievement' | 'random';
  value: number;
  target?: string;
}
```

## 3. 梗触发机制

### 3.1 触发条件检查

```python
def check_meme_unlock(agent: Agent, meme: Meme) -> bool:
    """
    检查是否解锁新梗
    """
    condition = meme.unlockCondition

    if condition.type == 'task_count':
        return agent.tasks_completed >= condition.value

    elif condition.type == 'collab_count':
        return agent.collaborations_completed >= condition.value

    elif condition.type == 'relationship':
        target = condition.target
        rel_value = agent.get_relationship(target)
        return rel_value >= condition.value

    elif condition.type == 'achievement':
        return agent.has_achievement(condition.value)

    elif condition.type == 'random':
        return random.random() < condition.value

    return False
```

### 3.2 梗使用概率

```python
# 梗使用概率配置
MEME_USAGE_PROBABILITY = {
    'common': 0.3,    # 30%概率使用
    'rare': 0.1,     # 10%概率使用
    'legendary': 0.02, # 2%概率使用
}

def should_use_meme(agent: Agent, context: str) -> Optional[Meme]:
    """
    决定是否在当前上下文使用梗
    """
    # 获取已解锁的梗
    unlocked_memes = agent.get_unlocked_memes()

    if not unlocked_memes:
        return None

    # 随机选择一个梗
    selected_meme = random.choice(unlocked_memes)

    # 根据稀有度决定是否使用
    probability = MEME_USAGE_PROBABILITY[selected_meme.rarity]

    if random.random() < probability:
        return selected_meme

    return None
```
