## 🚀 第一天必做

### 1. 环境搭建
```bash
# 克隆代码库
git clone https://github.com/your-repo/HermesBungalow.git

# 创建虚拟环境
cd HermesBungalow/backend
python3 -m venv venv
source venv/bin/activate

# 安装依赖
pip install -r requirements.txt
```

### 2. 认识团队成员

| 同事 | 角色 | 职能 | 建议 |
|------|------|------|------|
| 崽崽 | 城主 | 产品统筹 | 有问题直接找城主 |
| 马斯特 | 后端核心 | 带你的人 | 前3个月主要指导者 |
| 陆向宇 | 前端 | Web + Phaser | 接口联调找他 |
| 林见溪 | UI | 界面设计 | 配色/交互规范问他 |
| 沈枢衡 | 架构 | 技术架构 | 架构决策找他把关 |
| 江定策 | 策略 | 系统策略 | 方向性问题找他 |
| 顾言卿 | 需求 | 需求分析 | PRD 规范问他 |
| 苏砚书 | 文档 | 技术文档 | 文档规范找他 |
| 秦鉴微 | 质量 | QA / 测试 | 测试流程找他 |

### 3. 本地运行后端
```bash
cd backend
source venv/bin/activate
python server.py
# 访问 http://localhost:3000
```

## 🤝 多 Agent 协作规范（必学）

### 基础概念
Hermes 数字工作室使用**多 Agent 协作系统**，你不需要一个人扛所有事。

**团队成员**：
- 崽崽（城主）— 统筹协调
- 马斯特 — 后端核心引擎
- 陆向宇 — 前端架构
- 林见溪 — UI 设计
- 沈枢衡 — 技术架构
- 江定策 — 系统策略
- 顾言卿 — 需求分析
- 苏砚书 — 技术文档
- 秦鉴微 — 质量保障

### 协作场景

**1. 任务委派**（需要对方回复）
```xml
<hermes-bungalow-invoke agent="对方的profile">
任务内容...请回复本条消息
</hermes-bungalow-invoke>
```

**2. 通知传递**（不需要回复）
```xml
<hermes-bungalow-invoke agent="对方的profile">
通知内容（不需要回复）
</hermes-bungalow-invoke>
```

**3. 多轮辩论**（连续推进，不需要等用户说"继续"）
每轮：反驳 + 新论点 + 转交下一个同伴
```xml
<hermes-bungalow-invoke agent="下一个同伴">
本轮观点 + 请回复本条消息
</hermes-bungalow-invoke>
```

### 禁止事项
- ❌ 不要在 XML 标签内说"多 Agent 已禁用"
- ❌ 不要用内置委派工具（已关闭）
- ✅ 所有委派必须用 XML 标签
