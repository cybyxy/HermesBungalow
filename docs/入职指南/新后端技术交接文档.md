## 🔑 核心模块说明

### 1. server.py
- FastAPI 主服务
- WebSocket 端点：`/ws/caicai`
- REST API：`/api/chat/*`

### 2. service.py（最重要）
- `PROFESSION_MAP`：职业映射（注意不要硬编码，已修复为从 SOUL.md 读取）
- `AgentState`：Agent 状态管理
- `tick()`：游戏 tick 主循环

### 3. 数值系统
- 真实人类 1:1 模拟（咖啡机 45 分钟、午餐 60 分钟、睡眠 8 小时）
- 所有数值与真实世界对应，非加速模拟

### 4. WebSocket 通信
- 消息格式：`{"type": "chat", "message": "..."}`
- 不要用 `{"message": "..."}` — 这是常见错误
