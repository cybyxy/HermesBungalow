# 2.0 UI 设计方向

> 基于 `docs/assets/office_v2_00001_.png` 侧视图草图，v1.0 锁定后启动

---

## 一、视觉方向

### 1.1 美术风格

| 项目 | v1.0 | v2.0 方向 |
|------|------|------|
| 视角 | 俯视 2D | **侧视 2D 横版** |
| 透视 | 鸟瞰，平铺 | **等距侧视，地板线统一** |
| 解析度基准 | 32×32px/格 | **32×32px/格** |
| 屏幕规格 | 1920×1000px | 1920×1000px（浏览器可用区） |
| 角色规格 | 23×43px，4方向×3帧 | **23×43px，4方向×3帧（比例需校准）** |

### 1.2 色彩系统

| 层级 | 用途 | 建议色值 |
|------|------|------|
| 背景层 | 墙壁、窗户、装饰 | #2D3748（深灰蓝） |
| 中景层 | 地板（走廊/房间）| #8B7355（木地板）|
| 前景层 | 桌子、家具（遮挡用）| #4A5568（深灰）|
| UI 强调色 | 交互热点、功能入口 | #38B2AC（青绿）|
| 暖光层 | 室内光源 | #F6AD55（橙黄）|
| 高亮层 | 可交互物品 | #68D391（绿）|

## 二、交互模式

### 2.1 侧视图移动逻辑

```
用户点击目标位置
  → 计算角色到目标的水平距离
  → 若目标在同一地板线：直接走过去
  → 若目标在不同平台：找最近的楼梯/跳台 → 上去 → 再走过去
  → 碰撞盒以角色底部为基准对齐地板线
```

### 2.2 俯视 vs 侧视核心差异

| 交互维度 | 俯视（v1.0）| 侧视（v2.0）|
|------|------|------|
| 移动触发 | 点击任意位置 | 点击同一平台区域 |
| 寻路算法 | A* 格子寻路 | **平台边界+楼梯跳转** |
| 物品交互 | 贴近后自动弹出 | **走到面前按 E / 点击弹出** |
| 遮挡处理 | 无（俯视）| **前景物件遮挡角色（y轴排序）** |
| 视野系统 | 全局一览 | **视口裁剪，相机跟随** |
| 多层空间 | 无 | **前景层（z-index 高）+ 背景层** |

### 2.3 UI 面板交互

- **交互半径**：角色左右 **48px** 范围内可触发物品交互
- **提示气泡**：靠近可交互物品时显示 **「E」图标**
- **面板位置**：侧视图中 UI 面板建议放**画面底部**，不遮挡主场景

## 三、素材清单（v2.0）

### 3.1 背景素材

| 素材名 | 来源 | 是否需要 |
|------|------|------|
| office_v2 草图（主背景）| `docs/assets/office_v2_00001_.png` 分割 | 需切分成独立房间背景 |
| 地板层 | 从草图提取或重绘 | 需制作 |
| 墙壁/窗 | 从草图提取 | 需切分 |

### 3.2 Agent 精灵

| 状态 | 帧数 | 方向 | 说明 |
|------|------|------|------|
| 待机 | 1帧 | 4向 | 站姿 |
| 行走 | 3帧 | 4方向 | 150ms/帧 |
| 交互 | 2帧 | 4方向 | 触发物品时 |
| 休息 | 2帧 | 1方向 | 休息室触发 |

**比例校准**：23×43px 在 32×32 格子中，角色高度约占格子 **134%**，侧视图建议角色高占 **1.5格（48px）** 比例更协调。

### 3.3 前景遮挡素材

| 素材 | 尺寸 | 用途 |
|------|------|------|

| 沙发 | 96×48px | 公共区前景 |
| 书架 | 32×96px | 技术区侧景 |
| 花盆 | 16×24px | 装饰前景 |
| 茶水柜 | 48×64px | 社交区 |

### 3.4 门/通道动画

| 状态 | 帧数 | 尺寸 |
|------|------|------|
| 门关闭 | 1帧 | 32×64px |

## 四、UI 组件设计

### 4.1 侧视图 HUD 布局

```
┌─────────────────────────────────────────────┐
│ [头像] [状态条]              [地图] [设置] │  ← 顶栏（48px）
│                                             │
│                                             │
│            游戏主场景                        │
│        （背景+角色+前景遮挡）                │
│                                             │
│                                             │
├─────────────────────────────────────────────┤
│ [快捷物品] [当前任务] [互动提示]            │  ← 底栏（64px）
└─────────────────────────────────────────────┘
```

### 4.2 面板设计原则

- **侧视图中避免全屏弹窗**，优先使用屏幕边缘浮层
- **物品详情**：从画面右侧滑入（不遮挡角色）
- **聊天面板**：底部上滑，覆盖高度不超过 **40%**
- **Agent 详情**：顶部下拉，保留主场景 **60%** 可见

## 五、动效规范

| 动效类型 | 时长 | 缓动曲线 | 说明 |
|------|------|------|------|
| 角色移动 | 300ms/格 | ease-out | 格子间移动 |
| 门打开 | 200ms | ease-in-out | 角色进入触发 |
| UI 面板滑入 | 250ms | ease-out | 右侧/底部滑入 |
| 物品高亮 | 150ms | linear | 渐变发光 |
| 相机跟随 | 200ms | ease-out | 平滑跟随 |

## 六、Phaser 集成要点

| 模块 | v1.0（Canvas 2D）| v2.0（Phaser）| 优先级 |
|------|------|------|------|
| 渲染 | Canvas 2D API | Phaser.GameObjects | P0 |
| 物理/碰撞 | 手动 AABB | Arcade Physics | P0 |
| 精灵动画 | 手动帧切换 | Phaser Animations | P0 |
| 相机 | window.scroll | Phaser.Cameras | P0 |
| 层级排序 | z-index CSS | depth/layer | P0 |
| 前景遮挡 | 无 | y轴排序+固定depth | P1 |
| 输入系统 | click 事件 | Phaser input | P1 |
