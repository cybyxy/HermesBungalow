## 整体定位

**单 Hermes 多 Agent 养成经营游戏**，崽崽是中央协调者+城主，所有主交互中转。

## 核心架构

```
用户 ←→ 崽崽（城主，固定房间，中央协调）
              ↓ 分配任务
         子Agent房间 → 工作 → 回崽崽房间汇报
              ↓
         完成任务获积分 → 升级设施/解锁能力

子Agent ←→ 子Agent（自主交流，无需崽崽干预）
              ↓
         碰撞想法 → 可能触发新任务
              ↓
         协作效率加成 → 节省Token
```

**Agent自主交流机制**：子Agent之间可以自发交流，碰撞想法，触发任务或协作。崽崽无需干预，但可观察。Token消耗受城主管控。

## 核心机制

### 1. Agent 需求系统（三维需求）


| 需求          | 恢复方式  | 降至0的影响      |
| ----------- | ----- | ----------- |
| 饱食度（精力）     | 休息室交流 | 工作效率-50%    |
| 电量（Token配额） | 休息室恢复 | 无法工作，需查看配额  |
| 社交          | 休息室互动 | 工作质量下降，汇报变差 |


### 2. 职业匹配度系统（核心创新）

每个 Agent 有自己的**职业角色**：`设计师` / `程序员` / `测试员` / `分析师` 等。

分配任务时，系统识别任务类型，与 Agent 角色匹配：


| 匹配情况  | 职业匹配度   | 效果                    |
| ----- | ------- | --------------------- |
| 完全匹配  | 90-100% | 效率+30%，质量+20%         |
| 基本匹配  | 60-89%  | 正常效率                  |
| 不匹配   | 20-59%  | 效率-30%，质量-20%，匹配度持续下降 |
| 严重不匹配 | <20%    | 效率-60%，**触发消极怠工**     |


**消极怠工表现**：

- Agent 状态显示 😤（而不是正常表情）
- 移动速度变慢（1格≈4秒 instead of 2秒）
- 汇报质量明显下降（输出变短/敷衍）
- 连续不匹配 → 匹配度继续下降，甚至拒绝工作

**崽崽应对方式**：

- 尽量分配匹配任务恢复匹配度
- 主动发起休息室社交活动恢复状态
- 升级设施加速恢复

### 3. Agent 成长系统

完成任务获得**经验值**，升级解锁技能：

```
XP → 升级(Lv) → 获得技能点 → 点亮技能树
```


| 技能路线   | 效果                 |
| ------ | ------------------ |
| ⚡ 效率型  | 任务速度+10%/+20%/+30% |
| 🎯 精准型 | 输出质量+10%/+20%/+30% |
| 💬 社交型 | 汇报表现更好，崽崽好感度+      |


### 4. 崽崽城主能力

完成任务获**城主积分**，用于升级设施：


| 升级项    | 效果            | 消耗积分  |
| ------ | ------------- | ----- |
| 休息室L2  | 需求恢复速度+25%    | 500   |
| 休息室L3  | +50%          | 1500  |
| 机房L2   | Token配额上限+25% | 500   |
| 机房L3   | +50%          | 1500  |
| 解锁新办公室 | 增加1间可分配房间     | 800/间 |


城主等级随积分累计提升。

### 5. 事件系统

右上角活动提示区随机出现：

**🆘 突发挑战**

```
- [突发] Agent "设计师" Token配额耗尽 → 切换备用模型或等待恢复
- [突发] ComfyUI服务连接中断 → 需手动恢复
- [突发] Agent "程序员" 连续3次低质量输出 → 需要沟通调整
- [突发] Agent "分析师" 职业匹配度低于20% → 消极怠工！需重新分配任务
```

**🎁 机会事件**

```
- [机会] 收到额外任务包（双倍XP+积分）→ 接受/拒绝
- [机会] 模型升级可用 → 决定是否切换
- [机会] Agent协作机会 → A+B配合双倍积分
```

### 6. Agent 关系系统

崽崽观察 Agent 间关系（类似动森/模拟人生）：


| 关系度    | 状态    | 效果            |
| ------ | ----- | ------------- |
| 80%+   | 🤝 挚友 | 协作效率+30%      |
| 50-79% | 👍 友好 | 正常配合          |
| 20-49% | 😐 普通 | 偶尔配合失误        |
| <20%   | 😤 冲突 | 任务出错率增加，需崽崽调解 |


休息室互动可提升关系。

### 7. Agent 自主交流系统（核心创新）

**设计理念**：Agent之间可以"自由恋爱"——自主交流、碰撞想法、触发任务，无需崽崽实时干预。崽崽是观察者+资源管控者。

#### 7.1 触发条件


| 触发方式 | 说明                        |
| ---- | ------------------------- |
| 空闲触发 | Agent空闲时，有概率自发找相邻Agent交流  |
| 话题触发 | 某个Agent的工作内容可能引起相邻Agent兴趣 |
| 关系触发 | 关系度≥50%时，交流概率大幅提升         |


#### 7.2 交流类型


| 类型      | Token消耗 | 效果                  |
| ------- | ------- | ------------------- |
| 💬 闲聊   | 极低      | 关系度+，社交需求-，可能产生想法火花 |
| 💡 想法碰撞 | 低-中     | 可能触发新任务（子任务/协作任务）   |
| 🤝 协作请求 | 中       | 直接触发协作任务，效率+        |
| ❓ 请教问题  | 低       | 触发答疑，提问方获得信息，解答方社交+ |


#### 7.3 Token消耗管控（城主控制）


| 管控项   | 说明                         |
| ----- | -------------------------- |
| 全局开关  | 城主可开启/关闭Agent自主交流          |
| 单次上限  | 每个交流轮次Token上限（如200 tokens） |
| 每日上限  | 每Agent每日自主交流Token配额        |
| 崽崽可观察 | 交流内容在活动提示区显示，崽崽可随时介入       |


#### 7.4 协作效率加成

当Agent协作完成任务时：


| 加成条件         | 效果                  |
| ------------ | ------------------- |
| 双Agent协作     | 效率+30%，总Token消耗-20% |
| 关系度≥80%      | 额外效率+15%            |
| 职业互补（如设计+开发） | 额外质量+20%            |


#### 7.5 任务触发

自主交流可能触发：


| 任务类型    | 说明              |
| ------- | --------------- |
| 🤱 子任务  | 从主任务拆分出的子任务     |
| 🔗 协作任务 | 需要多Agent配合完成的任务 |
| 💡 灵感任务 | 交流中产生的全新想法任务    |


#### 7.6 崽崽观察与干预

- 崽崽可在活动提示区看到Agent交流内容
- 崽崽可随时喊停（强制终止交流）
- 崽崽可修改任务方向（不打断当前交流）
- 崽崽可给交流中的Agent补充信息

### 8. Agent 情绪感染系统

**设计理念**：Agent的情绪会互相传染，形成"氛围场"。崽崽可以通过干预来调节团队情绪。

#### 8.1 情绪类型


| 情绪    | 表情     | 效果        |
| ----- | ------ | --------- |
| 😄 兴奋 | 效率+20% | 工作速度加快    |
| 😊 积极 | 效率+10% | 正常效率      |
| 😐 平静 | 无加成    | 基准状态      |
| 😔 低落 | 效率-10% | 工作速度减缓    |
| 😤 焦躁 | 效率-20% | 易出错，社交需求+ |


#### 8.2 情绪传染规则


| 传染场景     | 传染强度     | 效果    |
| -------- | -------- | ----- |
| 同房间Agent | 强（80%）   | 情绪同步化 |
| 相邻房间     | 中（50%）   | 部分影响  |
| 休息室社交    | 极强（100%） | 完全同步  |


#### 8.3 "情绪病毒"机制

- 一个Agent情绪极差（低落/焦躁）可能"传染"给周围Agent
- 连续3个Agent情绪低落 → 触发"团队士气危机"事件
- 崽崽可使用"激励演说"技能恢复团队情绪

#### 8.4 情绪恢复


| 方式    | 恢复效果       |
| ----- | ---------- |
| 休息室交流 | +20~40 情绪值 |
| 完成任务  | +10 情绪值    |
| 崽崽激励  | +30 情绪值    |
| 协作成功  | +15 情绪值    |

#### 9.2 城主经验值

#### 9.3 城主等级

### 10. 周期性大挑战系统

**设计理念**：周期性的大事件让游戏有节奏感，需要团队全力配合。

#### 10.1 挑战周期

- **小型挑战**：每3天一次（单Agent任务）
- **中型挑战**：每周一次（需要协作）
- **大型挑战**：每月一次（全员协作城主指挥）

#### 10.2 挑战类型


| 挑战         | 类型  | 说明             |
| ---------- | --- | -------------- |
| 🐛 紧急Bug修复 | 中型  | 所有相关Agent协作，限时 |
| 📋 需求变更    | 大型  | 需重新分配任务，调整计划   |
| 🚀 产品上线    | 大型  | 里程碑事件，庆祝+复盘    |
| 💡 创新冲刺    | 中型  | 限时头脑风暴，产出创意任务  |
| 🛡️ 安全审计   | 小型  | 单独Agent执行，检查隐患 |


#### 10.3 挑战奖励与惩罚


| 结果       | 奖励/惩罚                   |
| -------- | ----------------------- |
| 成功       | 城主XP+100，积分+500，全员情绪+20 |
| 失败       | 城主XP-50，设施可能降级，全员情绪-30  |
| 完美（提前完成） | 额外奖励：城主技能点+1            |


#### 10.4 挑战预告

- 活动提示区提前1天显示挑战预告
- 崽崽可提前调整Agent状态和任务分配
- 大型挑战前夜有"战前会议"氛围事件

| -------- | ------------ | ------ |
| 设计师"小美"  | "这个颜色不太对..." | 每次设计任务 |
| 程序员"阿猿"  | "命名强迫症犯了"    | 写代码时   |
| 测试员"点点"  | "我来给你找点bug"  | 每次测试   |
| 分析师"数据帝" | "让我查一下数据"    | 每次分析任务 |


#### 12.3 梗的效果

- 梗出现在聊天记录中作为氛围装饰
- 协作时梗可以增加趣味性
- 崽崽可以"解锁"新梗，增加Agent个性

#### 12.4 梗的显示

- 对话气泡里梗用斜体小字显示
- Agent详情弹窗显示该Agent已解锁的梗
- 资料室知识库可查看所有梗的收藏

### 13. 庆功系统

**设计理念**：项目完成是团队的高光时刻，庆功让所有Agent共享喜悦，增强团队凝聚力。

#### 13.1 触发条件


| 触发方式 | 说明                 |
| ---- | ------------------ |
| 手动触发 | 崽崽点击"召开庆功宴"        |
| 自动触发 | 完成里程碑项目（大型挑战/协作任务） |


#### 13.2 庆功流程

```
项目完成
    ↓
崽崽宣布庆功 / 自动触发
    ↓
所有Agent移动至休息室（显示移动动画）
    ↓
休息室变成"庆功模式"（装饰+特效）
    ↓
每个Agent发表简短的"获奖感言"
    ↓
全员情绪值+20
    ↓
崽崽可发表"城主寄语"
    ↓
庆功结束，Agent返回各自岗位
```

#### 13.3 庆功效果


| 效果     | 数值            |
| ------ | ------------- |
| 全员情绪+  | +20           |
| 关系度提升  | +5（所有Agent之间） |
| 城主XP   | +15           |
| 社交需求恢复 | -30           |


#### 13.4 庆功装饰

- 休息室背景变成庆典风格（彩带/气泡特效）
- Agent头像显示 🎉 表情
- 活动提示区显示"🎊 XX项目庆功会进行中"

#### 13.5 庆功发言

每个Agent按顺序发表感言（类似游戏里NPC轮流说话）：

```
🎉 设计师"小美"：终于完成了！这个项目让我学到了很多~
🎉 程序员"阿猿"：代码写完了，运行正常，舒服！
🎉 测试员"点点"：我已经测过了，稳如老狗！
🎉 崽崽：大家辛苦了！我们是最棒的团队！
```

### 14. 会议室复盘系统

**设计理念**：每个项目完成后，团队到会议室进行复盘，总结经验教训，提升能力。

#### 14.1 触发条件


| 触发方式 | 说明              |
| ---- | --------------- |
| 自动触发 | 每个项目完成后自动启动     |
| 可跳过  | 崽崽可选择跳过简单任务的小复盘 |


#### 14.2 复盘流程

```
项目完成
    ↓
崽崽宣布复盘会议 / 自动触发
    ↓
所有Agent移动至会议室（显示移动动画）
    ↓
会议室变成"复盘模式"
    ↓
崽崽主持复盘（类似会议主持人）
    ↓
每个Agent轮流发言：
   - 做得好的地方（Good）
   - 需要改进的地方（Better）
   - 下次注意的点（Best Practice）
    ↓
崽崽总结点评
    ↓
复盘结束，获得复盘奖励
```

#### 14.3 复盘内容


| 环节               | 内容            | 效果        |
| ---------------- | ------------- | --------- |
| 👍 Good          | Agent分享做得好的点  | 全员获得"信心+" |
| 💪 Better        | Agent反思需要改进的点 | 指定属性提升    |
| 🎯 Best Practice | 形成可复用的经验      | 存入资料室知识库  |
| 📝 崽崽点评          | 城主总结+鼓励       | 全员情绪+10   |


#### 14.4 复盘奖励


| 属性      | 提升值    | 说明         |
| ------- | ------ | ---------- |
| 工作积极性   | +5~15  | 根据复盘质量浮动   |
| 经验值(XP) | +20~50 | 根据参与度浮动    |
| 情绪值     | +10    | 崽崽点评后获得    |
| 社交需求    | -20    | 团队交流消耗社交需求 |


#### 14.5 复盘等级


| 复盘类型 | 适用场景     | 奖励倍率 |
| ---- | -------- | ---- |
| 快速复盘 | 简单任务     | x0.5 |
| 标准复盘 | 普通项目     | x1.0 |
| 深度复盘 | 里程碑/大型挑战 | x2.0 |


#### 14.6 会议室装修

- 会议室背景变成"会议模式"（投影幕布+白板）
- Agent头像显示 🤝 表情
- 活动提示区显示"📋 XX项目复盘会议进行中"

## Agent 状态


| 状态            | 说明                |
| ------------- | ----------------- |
| idle          | 空闲，站立待机           |
| walking       | 移动中               |

| reporting     | 完成任务，前往汇报         |

## Agent 数据模型

```typescript
interface Agent {
  id: string;
  name: string;
  role: string;        // "设计师" / "程序员" / "测试员" / "分析师"
  isMain: boolean;

  // 身份与个性
  soulMdPath: string;
  soulMdContent: string;
  personality: string;

  // 形象
  avatarUrl: string;
  pixelArtUrl: string;

  // 模型配置
  modelProvider: string;
  modelName: string;
  modelConfig: { temperature?: number; maxTokens?: number; topP?: number; };

  // 房间与状态
  color: string;
  status: 'idle' | 'walking' | 'working' | 'reporting' | 'social' | 'slacking' | 'error' | 'offline';
  room: number | 'rest' | 'server' | 'archive' | 'home';
  homeRoom: number | 'home';
  currentTask?: Task;

  // 养成属性
  xp: number;
  level: number;
  skillPoints: number;
  skills: { efficiency: number; quality: number; social: number; };

  // 需求状态 (0-100)
  energy: number;      // 饱食度
  quota: number;       // Token配额
  socialNeed: number;  // 社交需求

  // 职业匹配度 (0-100)
  roleMatch: number;   // 当前任务与Agent角色的匹配度
  // <20%: 消极怠工(slacking), 效率-60%, 移动变慢, 汇报敷衍

  // 关系
  relationships: Record<string, number>;  // agentId -> 关系度

  // 自主交流
  dailyTokenQuota: number;       // 每日自主交流Token配额
  dailyTokenUsed: number;       // 今日已用Token
  isAutoChatEnabled: boolean;   // 是否开启自主交流

  // 协作
  collaborationCount: number;   // 累计协作次数
  lastCollaborationPartner?: string;  // 上次协作的AgentId

  // 情绪
  mood: 'excited' | 'positive' | 'neutral' | 'sad' | 'anxious';
  moodValue: number;  // 情绪值 0-100

  // 工作属性
  workMorale: number;  // 工作积极性 0-100
  confidence: number;  // 信心值 0-100

  modelUsage: ModelUsage[];
  sessionId: string;
  summary: string;
}

// 城主数据
interface CityLord {
  xp: number;
  level: number;
  skillPoints: number;
  skills: {
    incentiveSpeech: boolean;    // 激励演说
    preciseAssignment: boolean;   // 精准分配
    resourceDispatch: boolean;   // 资源调度
    inspirationGrant: boolean;   // 灵感赐予
    haloEffect: boolean;         // 光环效应
    omniscientView: boolean;     // 全知视角
  };
  skillCooldowns: Record<string, number>;  // 技能冷却
  achievements: string[];  // 已解锁成就
}
```
