# 数字小屋 UI 素材文档

## 概述

本目录包含数字小屋游戏的 UI 素材，采用 **Rimworld 风格**：
- 透明背景（PNG 格式）
- 简约像素画风
- 按实际比例设计尺寸

## 布局规则

### 工作区
- 木桌 (80×48) 作为主工作台
- 电脑显示器 (32×16) 放在桌上偏上位置
- 键盘 (16×16) 放在显示器前
- 椅子 (32×32) 放在桌前

### 休息区
- 咖啡桌 (48×32) 作为茶几
- 咖啡杯 (16×16) 放在咖啡桌上
- 沙发 (80×32) 靠墙
- 盆栽 (16×16) 角落装饰

## 使用方式

1. 打开 `prototype.html` 在浏览器中预览 UI 原型
2. 素材图片可直接用于游戏开发
3. 保持 `image-rendering: pixelated` 确保像素风格不失真

## 设计原则

1. **透明背景**：所有素材都是透明背景，便于叠加组合
2. **简约风格**：去除复杂纹理，保持像素游戏简洁美感
3. **比例准确**：
   - 电脑比电脑桌小
   - 键盘比显示器小
   - 咖啡杯比咖啡桌小
   - 咖啡桌比木桌小
4. **可平铺**：地板和墙面素材支持无缝平铺
