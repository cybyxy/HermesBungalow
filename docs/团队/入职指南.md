## 2. 环境搭建

### 2.1 克隆与配置

```bash
# 克隆代码库
git clone https://github.com/your-repo/HermesBungalow.git

# 创建虚拟环境
cd HermesBungalow/backend
python3 -m venv venv
source venv/bin/activate

# 安装依赖
pip install -r requirements.txt
```

> **注意 Python 版本**：系统 Python 3.14 可能存在依赖缺失。如果遇到问题，可尝试 `/Users/bobo/.hermes/hermes-agent/venv/bin/python3`（macOS 环境参考路径）。

### 2.2 本地运行

```bash
cd backend
source venv/bin/activate
python server.py
# 访问 http://localhost:3000
```

```

│   ├── agents/
│   │   └── *.py               # Agent 行为定义
│   └── data/
│       └── bungalow.db        # SQLite 数据库
├── frontend/
│   └── src/                   # Next.js + Phaser
└── docs/                      # 文档
```

### 模块说明

**server.py**
- FastAPI 主服务
- WebSocket 端点：`/ws/caicai`
- REST API：`/api/chat/*`

**service.py（最重要）**
- `PROFESSION_MAP`：职业映射（注意不要硬编码，已修复为从 SOUL.md 读取）
- `AgentState`：Agent 状态管理
- `tick()`：游戏 tick 主循环

**数值系统**
- 真实人类 1:1 模拟（咖啡机 45 分钟、午餐 60 分钟、睡眠 8 小时）
- 所有数值与真实世界对应，非加速模拟

**WebSocket 通信**
- 消息格式：`{"type": "chat", "message": "..."}`
- 不要用 `{"message": "..."}` — 这是常见错误

## 4. 多 Agent 协作规范（必学）

### 基础概念

Hermes 数字工作室使用**多 Agent 协作系统**，你不需要一个人扛所有事。团队成员对应上一节介绍的九位同事，每位同事在系统中都有对应的 Agent Profile，可通过 XML 标签进行协作调用。

### 协作场景

**1. 任务委派（需要对方回复）**

```xml
<hermes-bungalow-invoke agent="对方的profile">
任务内容...请回复本条消息
</hermes-bungalow-invoke>
```

**2. 通知传递（不需要回复）**

```xml
<hermes-bungalow-invoke agent="对方的profile">
通知内容（不需要回复）
</hermes-bungalow-invoke>
```

**3. 多轮辩论（连续推进，不需要等用户说"继续"）**

每轮：反驳 + 新论点 + 转交下一个同伴

```xml
<hermes-bungalow-invoke agent="下一个同伴">
本轮观点 + 请回复本条消息
</hermes-bungalow-invoke>
```

### 禁止事项

- 不要在 XML 标签内说"多 Agent 已禁用"
- 不要用内置委派工具（已关闭）
- 所有委派必须用 XML 标签

## 5. 常见坑

| 坑 | 原因 | 解决方案 |
|----|------|----------|
| 职业显示不正确 | `PROFESSION_MAP` 硬编码 | 从 SOUL.md 读取 |
| WebSocket 消息格式错 | 用错格式 | 必须是 `{"type": "chat", ...}` |
| Python venv 用错 | 系统 Python 3.14 缺少依赖 | 用项目 venv 中的 Python |

## 6. 融入计划

**第一阶段（0-1 个月）**：熟悉代码库
- 跟马斯特 1v1 每天 30 分钟 code review
- 承接：修复 bug 或小功能

**第二阶段（1-2 个月）**：独立开发
- 承接一条业务线，如「任务系统」或「社交系统」
- 开始参与接口设计讨论

**第三阶段（2-3 个月）**：独立负责
- 独立负责 1-2 条业务线
- 开始参与数值系统讨论
