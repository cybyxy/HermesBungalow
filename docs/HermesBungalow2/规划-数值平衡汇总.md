## 1. 任务竞争奖惩数值设计

### 1.1 基础奖惩（抽签结果）

| 结果 | 情绪变化 | 关系变化 | 持续时间 |
|------|----------|----------|----------|
| 抢到任务（赢家） | **+8~15** | — | 即时 |
| 没抢到（输家） | **-5~10** | 与赢家 **-3~-5** | 30分钟 |

**数值推导逻辑**：
- 赢家情绪+8~15：中等正反馈，约等于完成1个简单任务的奖励（简单任务奖励10-15积分，情绪+10）
- 输家情绪-5~10：负面心理波动，约等于完成1个失败任务的惩罚
- 输家与赢家关系-3~-5：嫉妒心理的量化表现，符合真实职场

### 1.2 特殊结果

| 结果 | 情绪变化 | 关系变化 | 持续时间 |
|------|----------|----------|----------|
| 抢到+完美完成 | **+30** | 与同事 **+3** | 即时 |
| 抢到+失败（加倍惩罚） | **-30~-50** | 与同事 **-5** | 3小时 |

**数值推导逻辑**：
- 完美完成的英雄感+30：约等于完成1个史诗任务的情绪奖励
- 加倍惩罚-30~-50：抢到机会却失败的机会成本量化
- 与同事关系+3/-5：成功/失败对团队关系的影响

### 1.3 加倍惩罚判定条件

满足任一条件即触发加倍惩罚：

| 判定条件 | 说明 |
|----------|------|
| 任务彻底失败 | TaskStatus = 'failed' |
| 进度严重落后 | 超时50%以上 |
| 城主评分<2分 |城主手动评分不通过 |

## 2. 连续失败计数器机制

### 2.1 机制设计

```typescript
interface CompetitionRecord {
  agentId: string;
  consecutive_losses: number;  // 连续失败次数
  last_loss_time: number;     // 上次失败时间
}
```

### 2.2 连续失败加成

| 连续失败次数 | 下次竞争情绪补偿 |
|--------------|------------------|
| 1次 | +3（安慰奖） |
| 2次 | +5 |
| 3次 | +8 |
| 4次+ | +10（上限） |

**设计理由**：
- 防止同一Agent连续失败后彻底失去参与动力
- 补偿数值递减，防止数值溢出
- 符合真实职场中"下次一定"的期待心理

### 2.3 计数器重置规则

| 事件 | 动作 |
|------|------|
| 竞争获胜 | 重置为0 |
| 超时30分钟未参与竞争 | -1（递减） |

## 3. 调参建议

### 3.1 敏感度分析

| 参数 | 调高影响 | 调低影响 | 建议范围 |
|------|----------|----------|----------|
| 赢家情绪+ | 激励增强，但可能过度竞争 | 动力不足 | 8~15 |
| 输家情绪- | 失落感强，可能引发消极 | 影响较小 | 5~10 |
| 关系惩罚 | 影响团队稳定性 | 协作氛围好 | 3~5 |
| 加倍惩罚 | 压力过大，可能消极怠工 | 压力适中 | 30~50 |

### 3.2 A/B测试建议

| 测试组 | 方案 | 预期效果 |
|--------|------|----------|
| A组 | 现有数值（+8~15 / -5~10） | 基准 |
| B组 | 温和版（+5~10 / -3~7） | 减少竞争压力 |
| C组 | 激进版（+10~20 / -7~15） | 增加竞争动力 |

**验证指标**：
- 7日留存率
- 人均任务完成数
- Agent间平均关系值
- 负面情绪累积情况

## 4. 数值平衡公式

### 4.1 情绪期望值公式

```
E(情绪) = P(赢) × 情绪奖励 + P(输) × 情绪惩罚

假设：P(赢) = 0.5（2人竞争）
E(情绪) = 0.5 × (+11.5) + 0.5 × (-7.5) = +2

结论：长期参与竞争，情绪期望值为正，鼓励参与
```

### 4.2 关系损耗公式

```
关系损耗 = -3 ~ -5（每次竞争失败）

假设：每日竞争3次，失败2次
每日关系损耗 = 2 × (-4) = -8
关系恢复（通过社交）= +5/次

平衡点：每日至少社交2次可抵消竞争关系损耗
```

## 5. 数值上限

| 属性 | 上限 | 原因 |
|------|------|------|
| 单次赢家情绪奖励 | +30 | 防止数值溢出 |
| 单次输家情绪惩罚 | -50 | 防止数值溢出 |
| 单次关系奖励 | +3 | 防止关系通胀 |
| 单次关系惩罚 | -5 | 防止关系崩溃 |
| 连续失败补偿上限 | +10 | 边际递减 |
| 关系惩罚持续时间 | 30分钟 | 真实心理恢复周期 |
| 加倍惩罚持续时间 | 3小时 | 压力消化周期 |

## 6. 数值平衡检查清单

- [ ] 赢家情绪奖励 ≥ 输家情绪惩罚的50%（保证参与动力）
- [ ] 关系惩罚 ≤ 每日社交恢复量的2倍（防止关系崩溃）
- [ ] 加倍惩罚 ≤ 完成失败任务的情绪损失（惩罚合理）
- [ ] 连续失败补偿能覆盖基础消耗的50%（防止彻底流失）
