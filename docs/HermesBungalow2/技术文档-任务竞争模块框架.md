## 一、模块概述

任务竞争模块用于解决"同职业多个 Agent 空闲时，任务分配给谁"的问题。触发后通过纯随机抽签决定任务归属。

### 1.1 核心定位

| 属性 | 值 |
|------|-----|
| 模块名称 | 任务竞争 |
| 英文名 | TaskCompetition |
| 触发场景 | 同职业 ≥2 个 Agent 空闲，同一任务只能分配给 1 人 |
| 分配方式 | 纯随机抽签（不举手、不先到先得） |
| 影响范围 | 情绪值、任务执行 |

### 2.2 核心类/函数

| 名称 | 类型 | 职责 |
|------|------|------|
| `check_competition_trigger()` | 函数 | 检查是否触发竞争条件 |
| `resolve_competition()` | 函数 | 执行抽签，返回赢家/输家 |

### 2.3 数据结构

```python
# competition.py

@dataclass
class CompetitionResult:
    task_id: str
    competing_agents: list[str]           # 参与竞争的 agent_id 列表
    winner_id: str                        # 赢家
    loser_ids: list[str]                 # 输家列表
    winner_emotion_delta: int             # 赢家情绪变化
    loser_emotion_delta: int              # 输家情绪变化
    completed_at: float                   # 时间戳

@dataclass
class CompetitionConfig:
    enabled: bool = True
    min_agents: int = 2                  # 最少参与人数
    winner_emotion_range: tuple[int, int] = (8, 15)
    loser_emotion_range: tuple[int, int] = (-10, -5)
    extra_penalty_threshold: float = 0.5  # 赢家任务完成度低于此值触发额外惩罚
```

## 三、触发条件

详见 PRD 文档，本文档只记录技术实现要点：

| 条件 | 技术描述 |
|------|---------|
| 同职业 | 从 `agents.profession` 字段读取，不从职业标签数组遍历 |
| ≥2 空闲 | `agent.status == 'idle'` 且 `agent.current_task is None` |
| 任务只能 1 人执行 | `task.required_agents == 1` |
| 非协作任务 | `task.is_collaborative == False` |

**触发检查入口**：`service.py` → `assign_task()`

```python
def assign_task(task_id: str) -> AssignmentResult:
    eligible = get_eligible_agents(task_id)
    if len(eligible) >= 2 and task.requires_single_agent():
        # 触发竞争
        return resolve_competition(task_id, eligible)
    elif len(eligible) == 1:
        return assign_to_single(eligible[0], task_id)
    else:
        return AssignmentResult(status="no_eligible_agents")
```

## 四、竞争流程

### 4.1 流程图

```
任务分配请求
    ↓
检查竞争触发条件（职业人数 ≥2）
    ↓
[竞争] ──是──→ 广播「⚡ 任务竞争！」事件
    │                    ↓
    │              收集空闲同职业 Agent
    │                    ↓
    │              纯随机抽签（random.choice）
    │                    ↓
    │              广播竞争结果（winner/losers）
    │                    ↓
    │              应用奖惩数值
    │              • 赢家：情绪 +8~15
    │              • 输家：情绪 -5~-10
    │              • 若赢家任务完成差：额外扣加倍
    │                    ↓
    └──否──→ 直接分配给唯一候选人
                      ↓
                 返回分配结果
```

### 4.2 抽签实现

```python
import random

def resolve_competition(task_id: str, agents: list[Agent]) -> CompetitionResult:
    winner = random.choice(agents)
    losers = [a for a in agents if a.id != winner.id]
    
    winner_delta = random.randint(8, 15)
    loser_delta = random.randint(-10, -5)
    
    return CompetitionResult(
        task_id=task_id,
        competing_agents=[a.id for a in agents],
        winner_id=winner.id,
        loser_ids=[a.id for a in losers],
        winner_emotion_delta=winner_delta,
        loser_emotion_delta=loser_delta,
        completed_at=time.time()
    )
```
